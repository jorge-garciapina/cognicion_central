# APRENDIZAJE_ESTRUCTURAL

Aplicación que utiliza estructuras ya dominadas como anclas para adquirir estructuras nuevas mediante mapeo, límites, desanclaje, transferencia y operación.

Los casos que prueban esta aplicación se encuentran en `05_casos_y_ejemplos/aprendizaje_estructural`.

## Papel dentro del artefacto integral

- **Función:** convertir estructuras conocidas en puentes temporales para adquirir y operar estructuras nuevas.
- **Entradas:** estructura ancla, estructura objetivo, estado del aprendiz, correspondencias, límites y tareas de transferencia.
- **Salidas:** secuencias de mapeo, desanclaje, práctica y verificación de operación independiente.
- **Consumidores:** procesos pedagógicos, explicaciones y casos de aprendizaje estructural.
- **Límite:** una analogía útil no equivale a identidad entre dominios; el proceso debe explicitar rupturas y superar el ancla.
