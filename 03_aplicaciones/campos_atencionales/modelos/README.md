# Modelos de campos atencionales

Modelos provisionales para convertir conocimiento estructurado en una entidad reconocible, habitable y recurrente para una audiencia.

## Contenido

- `modelo_backend_frontend_campos_atencionales.md`: separa arquitectura interna, experiencia visible, secciones productivas, realizaciones y retroalimentación.
- `modelo_pertenencia_atencional_racionalizada.md`: integra segmentación, autorreferencia, identidad, propiedad psicológica, racionalización, secciones y conversión.
- `principios_psicologicos`: adapta principios y mecanismos psicológicos a publicidad, pertenencia, personalización y diseño de atención.

Cuatro de las nueve dependencias declaradas por el segundo documento están materializadas y cinco continúan pendientes. Tres modelos psicológicos se encuentran activos en `principios_psicologicos`; `modelo_entidades_organizadoras_atencion.md` sólo está disponible como antecedente sustituido en `90_historial/desarrollo_conceptual/campos_atencionales`. Deben consultarse sus referencias y el registro de deudas antes de usar el modelo como sistema cerrado.

## Papel dentro del artefacto integral

- **Función:** convertir la intención de un campo atencional en arquitecturas de experiencia, pertenencia y operación interna.
- **Entradas:** objetivos del campo, conocimiento, modelos expresivos, principios psicológicos y dependencias trazadas.
- **Salidas:** configuraciones provisionales de backend, frontend, secciones, pertenencia, realización y conversión.
- **Consumidores:** diseñadores de campos atencionales y procesos de creación de contenido relacionados.
- **Límite:** las dependencias ausentes impiden tratar el conjunto como sistema cerrado o completamente implementable.
