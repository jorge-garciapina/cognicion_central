# Nuevo entendimiento: relación entre Campo Atencional, UOA, secciones y realizaciones

**Documento:** `nuevo_entendimiento_uoa_campo_atencional.md`  
**Tema:** Reubicación conceptual de la Unidad Organizadora de Atención dentro de la ACCD  
**Estado:** Entendimiento actualizado para desarrollo posterior

---

# 1. Tesis central

La **Unidad Organizadora de Atención** no debe entenderse como una entidad superior al campo atencional, ni como equivalente al campo atencional completo.

La relación correcta es:

```txt
campo_atencional
  → UOA
    → secciones_de_la_UOA
      → piezas / unidades / manifestaciones
        → realizaciones_codominiales
```

Es decir:

```txt
La UOA se desprende de un campo atencional.
```

Una UOA es una organización local, situada y recorrible de una parte del campo atencional. El campo atencional puede generar muchas UOA, y cada UOA puede tener sus propias secciones, recorridos, ritmos, señales de entrada, piezas y formas de manifestación.

La formulación compacta sería:

```txt
UOA = unidad derivada de un campo atencional que organiza localmente atención.
```

---

# 2. Corrección jerárquica

La lectura anterior podía sugerir una relación como esta:

```txt
UOA
  → campo_atencional
```

Esa lectura debe descartarse.

La relación actualizada es:

```txt
campo_atencional
  → UOA
```

Esto implica que el campo atencional es el sistema mayor y la UOA es una entidad derivada.

El campo atencional contiene el dominio temático-cognitivo amplio, mientras que la UOA organiza una porción de ese campo dentro de una superficie, entorno, plataforma, entidad o contexto de consumo específico.

Ejemplo:

```txt
campo_atencional_publicidad
  → UOA_youtube_1
  → UOA_youtube_2
  → UOA_tiktok_1
  → UOA_tiktok_2
  → UOA_tiktok_3
  → UOA_instagram
```

Todas esas UOA pueden desprenderse del mismo campo atencional, pero cada una organiza la atención de forma distinta.

---

# 3. Campo atencional

Un **campo atencional** es un sistema amplio de organización temática, cognitiva y productiva de atención.

Puede estar centrado en un tema, una práctica, un problema, una industria, una disciplina, una comunidad, un tipo de deseo, una forma de conocimiento o una arquitectura de monetización.

Ejemplo:

```txt
campo_atencional_publicidad
campo_atencional_psicologia_del_consumidor
campo_atencional_historia_de_la_publicidad
campo_atencional_estrategia_de_contenidos
campo_atencional_educacion_financiera
```

El campo atencional no se agota en una sola salida, ni en una sola plataforma, ni en una sola entidad.

Un campo atencional puede tener:

```txt
múltiples UOA
múltiples secciones
múltiples realizaciones
múltiples piezas
múltiples recorridos
múltiples públicos parciales
múltiples formas de monetización
```

Por eso, el campo atencional debe entenderse como una entidad más amplia que sus manifestaciones concretas.

---

# 4. Unidad Organizadora de Atención

Una **Unidad Organizadora de Atención** es una entidad derivada de un campo atencional que organiza localmente atención.

La UOA puede tomar forma de:

```txt
canal de YouTube
cuenta de TikTok
perfil de Instagram
newsletter
comunidad digital
podcast
sitio web
marketplace temático
plataforma educativa
revista digital
tienda temática
serie editorial
```

Pero la UOA no se define únicamente por su plataforma. Se define por su función organizadora.

Una UOA:

```txt
convoca una parte del campo atencional
ordena esa atención localmente
crea secciones internas
establece recorridos de consumo
produce expectativas recurrentes
aloja piezas o unidades
usa señales de entrada
puede monetizar atención
puede usar distintas realizaciones codominiales
```

La UOA es, por tanto, una instancia organizadora del campo, no el campo entero.

---

# 5. Diferencia entre campo atencional y UOA

La diferencia puede formularse así:

```txt
campo_atencional
  = sistema temático-cognitivo amplio
  = dominio general de atención organizada
  = puede desplegar múltiples UOA
  = puede producir múltiples realizaciones
  = puede contener múltiples lógicas de salida

UOA
  = entidad organizadora derivada
  = organiza atención localmente
  = tiene secciones propias
  = tiene recorridos propios
  = tiene identidad operativa propia
  = puede usar varias realizaciones
```

Ejemplo:

```txt
campo_atencional_publicidad
  no es lo mismo que
  UOA_youtube_1
```

El campo atencional puede abarcar historia de la publicidad, copywriting, psicología del consumidor, análisis de campañas, estrategia de medios, evolución tecnológica y monetización.

Una UOA específica, como `UOA_youtube_1`, puede organizar sólo una parte de ese campo, por ejemplo:

```txt
UOA_youtube_1:
  canal dedicado a análisis histórico de campañas publicitarias
```

Otra UOA, como `UOA_tiktok_1`, puede organizar otra parte:

```txt
UOA_tiktok_1:
  cuenta dedicada a hooks, anuncios curiosos y microanálisis de atención
```

Ambas pertenecen al mismo campo, pero no son la misma organización.

---

# 6. Relación entre UOA y secciones

Una UOA tiene secciones propias.

La relación es:

```txt
UOA
  → sección_de_UOA
```

Ejemplo:

```txt
UOA_youtube_1
  → UOA_youtube_1-seccion_a
  → UOA_youtube_1-seccion_b
  → UOA_youtube_1-seccion_c
```

Otro ejemplo:

```txt
UOA_youtube_2
  → UOA_youtube_2-seccion_a
  → UOA_youtube_2-seccion_b
  → UOA_youtube_2-seccion_c
  → UOA_youtube_2-seccion_d
  → UOA_youtube_2-seccion_e
  → UOA_youtube_2-seccion_f
```

La sección no debe entenderse como un nombre global independiente. Su identidad depende de la UOA a la que pertenece.

---

# 7. Regla de identidad contextual de las secciones

Esta es una regla central del nuevo entendimiento:

```txt
UOA_youtube_1-seccion_a
  ≠
UOA_youtube_2-seccion_a
```

Aunque ambas tengan el nombre local `seccion_a`, son entidades distintas.

La razón es que una sección se identifica por su ruta de pertenencia, no sólo por su etiqueta local.

La identidad completa de una sección debe incluir:

```txt
campo_atencional_origen
UOA_de_pertenencia
nombre_local_de_seccion
función_dentro_de_la_UOA
```

Por tanto:

```yaml
id: UOA_youtube_1.seccion_a
nombre_local: seccion_a
pertenece_a: UOA_youtube_1
campo_atencional_origen: campo_atencional_publicidad
```

Y:

```yaml
id: UOA_youtube_2.seccion_a
nombre_local: seccion_a
pertenece_a: UOA_youtube_2
campo_atencional_origen: campo_atencional_publicidad
```

No deben fusionarse.

La regla general es:

```txt
La sección no se identifica sólo por su nombre local.
Se identifica por su ruta de pertenencia.
```

# 10. Relación entre UOA y realizaciones

Dentro de la ACCD, el campo atencional puede tener más de una forma de manifestación.

Hasta ahora se han desarrollado, por lo menos:

```txt
video_corto
carousel
```

Estas son realizaciones codominiales: formas concretas en las que una construcción conceptual puede materializarse.

La UOA organiza dónde, cómo y bajo qué secciones aparecen esas realizaciones.

La relación puede formularse así:

```txt
campo_atencional
  → UOA
    → sección_de_UOA
      → pieza
        → realización_codominial
```

Ejemplo:

```txt
campo_atencional_publicidad
  → UOA_tiktok_1
    → UOA_tiktok_1-seccion_a
      → pieza_001
        → video_corto
```

Otro ejemplo:

```txt
campo_atencional_publicidad
  → UOA_instagram
    → UOA_instagram-seccion_e
      → pieza_002
        → carousel
```

Esto implica que una UOA puede usar varias realizaciones.

Ejemplo:

```txt
UOA_youtube_1
  → video_corto
  → video_largo
  → carousel_resumen
  → post_comunitario
  → newsletter_derivada
```

La UOA no es una realización. La UOA organiza atención. La realización materializa piezas.

---

# 11. Distinción entre UOA y realización

La diferencia es:

```txt
UOA
  = entidad que organiza atención localmente

realización
  = forma codominial de materialización de una pieza
```

Ejemplo:

```txt
UOA_tiktok_1
  no es igual a video_corto
```

`UOA_tiktok_1` es una entidad organizadora de atención.

`video_corto` es una forma de manifestación.

Una UOA de TikTok usará principalmente videos cortos, pero eso no significa que la UOA sea idéntica a la realización `video_corto`.

Del mismo modo:

```txt
UOA_instagram
  no es igual a carousel
```

Una UOA de Instagram puede usar carousel, video corto, imagen única, stories, lives o posts textuales.

---

# 12. Grafo actualizado

El grafo debe leerse como un despliegue del campo atencional hacia UOA y de cada UOA hacia sus secciones.

```txt
campo_atencional-tema_1
  → UOA_youtube_1
  → UOA_youtube_2
  → UOA_tiktok_1
  → UOA_tiktok_2
  → UOA_tiktok_3
  → UOA_instagram
```

Después:

```txt
UOA_youtube_1
  → UOA_youtube_1-seccion_a
  → UOA_youtube_1-seccion_b
  → UOA_youtube_1-seccion_c
```

Y:

```txt
UOA_youtube_2
  → UOA_youtube_2-seccion_a
  → UOA_youtube_2-seccion_b
  → UOA_youtube_2-seccion_c
  → UOA_youtube_2-seccion_d
  → UOA_youtube_2-seccion_e
  → UOA_youtube_2-seccion_f
```

El grafo representa una estructura de pertenencia y despliegue:

```txt
campo
  contiene/desprende
    UOA
      contiene/desprende
        secciones
```

# 14. Modelo de nodo recomendado

Para evitar ambigüedad, cada nodo debería tener una estructura mínima.

## Nodo de campo atencional

```yaml
id: campo_atencional_publicidad
tipo: campo_atencional
tema_o_dominio: publicidad
funcion: sistema amplio de organización temática, cognitiva y productiva de atención
```

## Nodo de UOA

```yaml
id: UOA_youtube_1
tipo: unidad_organizadora_de_atencion
campo_atencional_origen: campo_atencional_publicidad
superficie_o_entorno: youtube
funcion: organizar localmente una parte del campo atencional en una entidad recorrible
```

## Nodo de sección de UOA

```yaml
id: UOA_youtube_1.seccion_a
tipo: seccion_de_UOA
nombre_local: seccion_a
pertenece_a: UOA_youtube_1
campo_atencional_origen: campo_atencional_publicidad
funcion: línea interna de organización, producción o recorrido dentro de la UOA
```

## Nodo de pieza

```yaml
id: pieza_001
tipo: pieza_o_manifestacion_local
pertenece_a: UOA_youtube_1.seccion_a
realizacion_codominial: video_corto
funcion: manifestación concreta producida dentro de una sección de UOA
```

# 15. Tipos de relación recomendados

El grafo no debería usar una única relación genérica para todo.

Conviene distinguir al menos estos tipos:

```txt
campo_desprende_UOA
UOA_contiene_seccion
seccion_produce_pieza
pieza_se_materializa_como_realizacion
UOA_usa_realizacion
seccion_usa_realizacion
```

Ejemplo:

```yaml
- origen: campo_atencional_publicidad
  destino: UOA_youtube_1
  tipo: campo_desprende_UOA

- origen: UOA_youtube_1
  destino: UOA_youtube_1.seccion_a
  tipo: UOA_contiene_seccion

- origen: UOA_youtube_1.seccion_a
  destino: pieza_001
  tipo: seccion_produce_pieza

- origen: pieza_001
  destino: video_corto
  tipo: pieza_se_materializa_como_realizacion
```

Esto permite que el grafo conserve la diferencia entre organización atencional y materialización codominial.

# 16. Implicaciones para diseño de campos atencionales

El nuevo entendimiento implica que diseñar un campo atencional no es sólo diseñar piezas.

Tampoco es sólo diseñar realizaciones como video corto o carousel.

Diseñar un campo atencional implica diseñar al menos cuatro capas:

```txt
1. campo_atencional
2. UOA derivadas
3. secciones internas de cada UOA
4. piezas materializadas mediante realizaciones
```

Ejemplo:

```txt
campo_atencional_publicidad
  → UOA_youtube_1
    → seccion_historia_de_campañas
      → video_largo
      → video_corto_derivado
      → carousel_resumen

  → UOA_tiktok_1
    → seccion_hooks_publicitarios
      → video_corto

  → UOA_instagram
    → seccion_casos_visuales
      → carousel
      → reel
```

El campo mantiene coherencia general, pero cada UOA organiza una experiencia particular.

---

# 17. Implicaciones para la ACCD

Este entendimiento encaja con la idea de que la ACCD puede producir múltiples salidas desde una misma arquitectura.

El campo atencional puede desprender UOA distintas.

Cada UOA puede tener secciones distintas.

Cada sección puede producir piezas distintas.

Cada pieza puede materializarse mediante una realización codominial distinta.

La arquitectura general sería:

```txt
ACCD
  → campo_atencional
    → UOA
      → seccion_de_UOA
        → pieza
          → realizacion_codominial
            → manifestacion_codominial
```

Esto permite articular dos ideas que antes podían confundirse:

```txt
UOA organiza atención.
Realización materializa una pieza.
```

Ambas pueden relacionarse, pero no son lo mismo.

# 19. Error conceptual a evitar

El error principal sería colapsar niveles.

## Error 1: confundir UOA con campo atencional

Incorrecto:

```txt
UOA_youtube_1 = campo_atencional_publicidad
```

Correcto:

```txt
UOA_youtube_1 ∈ despliegue_de campo_atencional_publicidad
```

## Error 2: confundir sección local con sección global

Incorrecto:

```txt
UOA_youtube_1-seccion_a = UOA_youtube_2-seccion_a
```

Correcto:

```txt
UOA_youtube_1-seccion_a ≠ UOA_youtube_2-seccion_a
```

## Error 3: confundir UOA con realización

Incorrecto:

```txt
UOA_tiktok_1 = video_corto
```

Correcto:

```txt
UOA_tiktok_1 usa video_corto como una posible realización dominante
```

## Error 4: confundir pieza con campo

Incorrecto:

```txt
una pieza viral = campo atencional
```

Correcto:

```txt
una pieza puede pertenecer a una sección, dentro de una UOA, derivada de un campo atencional
```

# 20. Fórmula final

La fórmula del nuevo entendimiento es:

```txt
campo_atencional
  → conjunto_de_UOA
    → cada_UOA_tiene_su_propia_estructura_interna
      → cada_UOA_contiene_secciones_no_colapsables
        → cada_seccion_produce_piezas
          → cada_pieza_se_materializa_en_una_realizacion_codominial
```

Y la síntesis más compacta:

```txt
La UOA es una organización local derivada del campo atencional.
La sección es una unidad interna contextualizada por su UOA.
La realización es la forma codominial que materializa una pieza.
```

# 21. Definición actualizada de UOA

```txt
Unidad Organizadora de Atención:
  entidad derivada de un campo atencional que organiza localmente una parte
  de ese campo mediante secciones propias, recorridos, señales de entrada,
  piezas, ritmos de consumo y posibles realizaciones codominiales.
```

---

# 22. Definición actualizada de sección de UOA

```txt
Sección de UOA:
  unidad interna de una Unidad Organizadora de Atención, identificada por su
  ruta de pertenencia, encargada de organizar una línea recurrente de producción,
  consumo, recorrido o expectativa dentro de esa UOA.
```

---

# 23. Definición actualizada de campo atencional

```txt
Campo Atencional:
  sistema amplio de organización temática, cognitiva y productiva de atención,
  capaz de desprender múltiples Unidades Organizadoras de Atención y de alimentar
  múltiples formas de manifestación codominial.
```

---

# 24. Conclusión

El nuevo entendimiento reubica la UOA dentro de la arquitectura de la ACCD.

La UOA no es el campo atencional completo. Tampoco es simplemente un canal o una realización.

La UOA es una entidad organizadora derivada del campo atencional.

Su función es organizar localmente una parte del campo mediante secciones propias. Esas secciones son entidades contextualizadas y no deben colapsarse con secciones de otras UOA aunque compartan el mismo nombre local.

La cadena final queda así:

```txt
campo_atencional
  → UOA
    → seccion_de_UOA
      → pieza
        → realizacion_codominial
          → manifestacion_codominial
```

Esta cadena será la base para explorar con mayor precisión cómo los campos atencionales se despliegan en entidades, secciones, piezas y salidas múltiples.
