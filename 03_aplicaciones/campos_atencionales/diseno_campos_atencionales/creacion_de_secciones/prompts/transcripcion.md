## Página 2

Es importante considerar que las realizaciones mencionadas tienen una [estructura de manifestación] lineal.

¿Qué significa esto?

Que tienen un principio y un fin.

Como comparación, la [manifestación codominial: "imagen"] no tiene una [estructura de manifestación] lineal. Explicación: una imagen tiene composición espacial, así que no tiene un "antes" y un "después", funciona como un todo.

Para modelar estas entidades lineales usaré la teoría “Event Segmentation Theory”, la cual dice:

“La Event Segmentation Theory (EST) estudia cómo las personas dividen una corriente continua de actividad en unidades significativas llamadas eventos. La idea central es que la experiencia no se procesa como una secuencia indiferenciada, sino como una sucesión de partes relativamente delimitadas. Esas partes pueden ser más amplias o más finas según el nivel de análisis.”

Evento:

Un evento es una unidad significativa de actividad. Puede ser una acción breve, una fase de una tarea o una unidad más amplia dentro de una secuencia.

Para el caso actual:

[Corriente continua de actividad] <=> {[Estructura de manifestación] lineal}

[Evento] <=> {[Unidad dentro de la manifestación]}

Pueden ser tanto los segmentos macro como manifestaciones (escena, lámina), o incluso partes internas de la manifestación.

Es importante notar que la teoría reconoce segmentación gruesa y segmentación fina.

## Sobre las Unidades Organizadoras de Atención

Es necesario complementar la discusión de la sección anterior con lo que ya se tiene en el documento llamado nuevo-entendimiento-uoa-campo-atencional.md.

Conviene extraer algunas cosas de ese documento:

1. Una UOA es una organización local, situada y recorrible de una parte del campo atencional. El campo atencional puede organizar muchas UOA, y cada UOA puede tener sus propias secciones, recorridos, ritmos, señales de entrada, piezas y formas de manifestación.

2. El campo atencional contiene el dominio-cognitivo amplio, mientras que la UOA organiza una porción de ese campo dentro de una superficie, entorno, plataforma, entidad o contexto de consumo específico.

3. Una UOA es una entidad derivada de un campo atencional que organiza localmente atención. Puede tomar forma de: canal de YT, cuenta TK, perfil de Instagram, newsletter, comunidad digital...

Pero la UOA no se define por su plataforma, sino por su función organizadora.

- convoca una parte del campo atencional
- crea secciones internas
- produce expectativas recurrentes
- usa señales de entrada
- puede usar distintas realizaciones codominiales
- ordena esa atención localmente
- establece recorridos de consumo
- aloja piezas o unidades
- puede monetizar atención

Con la formulación propuesta ya se tiene una base teórica para la creación de secciones, campos atencionales y UOA, lo cual es un gran avance.

Ahora es tiempo de entender cómo usarlo.

Los módulos del MAANC ya permiten construir corrientes de continuidad compuestas por eventos cognitivos.

En una realización lineal cada uno de estos eventos cognitivos cumple con una función.

Esto no es nuevo, es el efecto opuesto del análisis que se hizo al texto, es decir: creación.

- Un tema tᵢ se puede crear a partir de combinar estructuras cognitivas provenientes de muchas fuentes.

- Una sección debe fijar algunos valores. Por ejemplo podríamos decir que la sección se construirá a partir del módulo Mⁱ ∈ MAANC, así, tendrá una corriente de continuidad:

mⱼⁱ = e₁ⁱ → e₂ⁱ → e₃ⁱ → e₄ⁱ → e₅ⁱ

Cada uno de los eventos cognitivos eⱼⁱ tendrá una forma característica, en todas las manifestaciones creadas para esta sección dichas funciones serán las mismas.

- Así, el procesamiento de un texto (o contenido) en crudo debe hacerse siguiendo estos pasos.

1. Aplicar el módulo Mⁱ al texto o textos.

2. Combinar las estructuras eⱼⁱ resultantes según se requiera.
