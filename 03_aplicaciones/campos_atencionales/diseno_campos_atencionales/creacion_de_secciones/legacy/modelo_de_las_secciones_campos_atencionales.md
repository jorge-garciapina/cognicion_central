# Modelo de las Secciones en Campos Atencionales

**id_documental:** `modelo_de_las_secciones_campos_atencionales`  
**tipo:** `modelo_arquitectonico`  
**ubicacion_sugerida:** `/campos_atencionales/modelos/modelo_de_las_secciones_campos_atencionales.md`  
**funcion:** definir qué es una sección dentro de un campo atencional, cómo se diferencia de tema, realización y manifestación, y cómo puede usarse como contenedor funcional de valor.

---

## 0. Principio rector

Una sección no debe confundirse con un tema, una realización ni una pieza concreta.

La sección es un **contenedor funcional recurrente** dentro de un campo atencional. Su función es ofrecer una forma particular de valor a la audiencia y organizar temas diversos bajo una misma operación editorial, cognitiva, práctica o atencional.

La fórmula base es:

```txt
seccion = contenedor funcional de valor

tema = materia tratable dentro de una seccion

realizacion = forma material en la que una seccion se manifiesta

manifestacion = pieza concreta producida dentro de una realizacion
```

Por tanto:

```txt
Historia de la publicidad
  no es necesariamente una seccion.
  Es mejor entenderla como tema.

Desmontajes de mecanismos publicitarios
  sí puede ser una seccion.
  Puede contener temas como historia de la publicidad,
  curiosidad, titulares, garantías, precio, Barnum effect,
  mail order, venta directa, etc.
```

---

## 1. Ubicación de la sección dentro de la arquitectura

La sección vive dentro de un campo atencional.

Una estructura general sería:

```txt
campo_atencional
  → secciones
    → temas
      → realizaciones
        → manifestaciones
```

O, con mayor precisión:

```txt
campo_atencional
  → eje_de_valor
    → seccion
      → tema
        → realizacion
          → manifestacion_codominial
```

Cada nivel responde una pregunta distinta:

```txt
campo_atencional:
  ¿Qué universo de atención se está organizando?

seccion:
  ¿Qué tipo recurrente de valor se ofrece dentro del campo?

tema:
  ¿De qué se habla dentro de esa sección?

realizacion:
  ¿En qué forma material aparece?

manifestacion:
  ¿Cuál es la pieza concreta producida?
```

Ejemplo:

```txt
campo_atencional:
  Publicidad como arquitectura de atención

seccion:
  Desmontajes de mecanismos

tema:
  Curiosidad publicitaria

realizacion:
  carousel

manifestacion:
  "5 formas en que un anuncio abre una brecha de información"
```

## 2. Diferencia entre sección, tema, realización y manifestación

### 2.1. Tema

Un tema es aquello de lo que se habla.

Ejemplos:

```txt
Historia de la publicidad
Barnum effect
Mail order advertising
Precio como señal de valor
Titulares
Venta directa
Garantías
Curiosidad publicitaria
Propiedad psicológica
Publicidad en televisión
```

El tema responde:

```txt
¿De qué trata esto?
```

Un tema puede aparecer en muchas secciones distintas.

Ejemplo:

```txt
tema:
  Historia de la publicidad

puede aparecer en:
  - Principios antiguos, aplicaciones modernas
  - Desmontajes de mecanismos
  - Evolución de formatos
  - Errores históricos que enseñan
  - Casos convertidos en modelo
```

---

### 2.2. Sección

Una sección es un contenedor funcional de valor.

No se define principalmente por el contenido temático, sino por el **tipo de operación** que realiza sobre los temas.

Responde:

```txt
¿Qué tipo de valor recurrente recibe la audiencia aquí?
```

Ejemplos de secciones:

```txt
Desmontajes de mecanismos
Principios antiguos, aplicaciones modernas
Psicología aplicada de la publicidad
Laboratorio de anuncios
Estrategias por formato
Errores que enseñan
Casos convertidos en modelo
Diagnóstico de piezas
Mitos publicitarios desmontados
Decisiones invisibles de un anuncio
```

Una sección puede contener muchos temas.

Ejemplo:

```txt
seccion:
  Psicología aplicada de la publicidad

temas posibles:
  - Barnum effect
  - curiosidad
  - propiedad psicológica
  - confianza bajo riesgo
  - racionalización verbal
  - precio como señal
  - autoimagen del comprador
```

---

### 2.3. Realización

Una realización es la forma material o codominial en la que puede aparecer una sección.

Responde:

```txt
¿En qué formato se materializa esta sección?
```

Ejemplos:

```txt
video_corto
carousel
video_largo
newsletter
hilo
clase
landing
podcast
```

La misma sección puede materializarse en varias realizaciones.

Ejemplo:

```txt
seccion:
  Principios antiguos, aplicaciones modernas

tema:
  Mail order advertising

realizaciones posibles:
  - video_corto
  - carousel
  - video_largo
  - newsletter
  - clase
```

---

### 2.4. Manifestación

La manifestación es la pieza concreta.

Responde:

```txt
¿Cuál es el objeto producido?
```

Ejemplo:

```txt
campo:
  Publicidad como arquitectura de atención

seccion:
  Principios antiguos, aplicaciones modernas

tema:
  Mail order advertising

realizacion:
  video_corto

manifestacion:
  "La regla del correo directo que hoy usan las landing pages"
```

## 3. La sección como contenedor funcional

Una sección no es sólo una etiqueta de organización. Es una unidad funcional que debe tener identidad, promesa, reglas de inclusión y capacidad de producción recurrente.

La sección debe poder responder:

```txt
¿Qué entra aquí?
¿Qué no entra aquí?
Qué tipo de transformación recibe un tema al entrar aquí?
Qué expectativa crea en la audiencia?
Qué tipo de valor produce repetidamente?
En qué realizaciones puede aparecer?
```

Por eso una sección debe entenderse como:

```txt
seccion
  = contenedor recurrente
  + promesa de valor
  + operación atencional
  + criterio de inclusión temática
  + forma de transformación
  + relación con realizaciones
```

---

## 4. Componentes de una sección

Una sección debería describirse mediante los siguientes componentes.

```yaml
seccion:
  id:
  nombre:
  definicion:
  promesa_de_valor:
  operacion_atencional:
  operacion_cognitiva:
  criterio_de_inclusion_de_temas:
  criterio_de_exclusion_de_temas:
  tipo_de_transformacion:
  relacion_con_el_campo:
  audiencia_implicada:
  expectativa_recurrente:
  temas_admisibles:
  realizaciones_compatibles:
  frecuencia_o_ritmo:
  ejemplos_de_manifestaciones:
  riesgos_de_confusion:
  criterios_de_validacion:
```

---

### 4.1. `id`

Identificador estable de la sección.

Ejemplo:

```yaml
id: seccion_desmontajes_de_mecanismos
```

Debe ser técnico, estable y reutilizable.

---

### 4.2. `nombre`

Nombre visible o editorial de la sección.

Ejemplo:

```yaml
nombre: Desmontajes de mecanismos
```

El nombre debe comunicar la forma de valor que la sección ofrece.

---

### 4.3. `definicion`

Explica qué es la sección.

Ejemplo:

```yaml
definicion: >
  Sección dedicada a descomponer piezas, campañas, técnicas o fenómenos
  publicitarios para revelar el mecanismo que los hace funcionar.
```

---

### 4.4. `promesa_de_valor`

Describe qué recibe la audiencia al entrar en esta sección.

Ejemplo:

```yaml
promesa_de_valor: >
  Entender cómo funciona internamente una estrategia publicitaria y poder
  reconocer ese mecanismo en otros contextos.
```

La promesa de valor diferencia una sección de otra.

---

### 4.5. `operacion_atencional`

Describe cómo la sección captura, ordena o sostiene la atención.

Ejemplos:

```txt
revelacion
comparacion
diagnostico
contraste
curiosidad
reconocimiento
aplicacion
secuencia
analisis_de_caso
```

Ejemplo:

```yaml
operacion_atencional: revelacion_analitica
```

---

### 4.6. `operacion_cognitiva`

Describe qué tipo de procesamiento mental promueve la sección.

Ejemplos:

```txt
descomponer
comparar
clasificar
diagnosticar
historizar
aplicar
abstraer
modelar
traducir
simplificar
```

Ejemplo:

```yaml
operacion_cognitiva: descomposicion_de_mecanismos
```

---

### 4.7. `criterio_de_inclusion_de_temas`

Define qué temas pueden entrar en la sección.

Ejemplo:

```yaml
criterio_de_inclusion_de_temas: >
  Entran temas que puedan analizarse como mecanismo, técnica, estructura,
  efecto o principio publicitario transferible.
```

Esto evita que la sección se convierta en una categoría vaga.

---

### 4.8. `criterio_de_exclusion_de_temas`

Define qué temas no entran en la sección.

Ejemplo:

```yaml
criterio_de_exclusion_de_temas: >
  No entran temas puramente históricos si no se extrae de ellos un mecanismo
  operativo o una estructura reutilizable.
```

---

### 4.9. `tipo_de_transformacion`

Explica qué le hace la sección al tema.

Ejemplo:

```yaml
tipo_de_transformacion: >
  Convierte un fenómeno publicitario en una estructura comprensible,
  comparable y reutilizable.
```

Un mismo tema cambia según la sección que lo contiene.

Ejemplo:

```txt
tema:
  Historia de la publicidad

si entra en "Principios antiguos, aplicaciones modernas":
  se transforma en lección transferible al presente.

si entra en "Evolución de formatos":
  se transforma en comparación entre medios.

si entra en "Errores que enseñan":
  se transforma en advertencia práctica.
```

---

### 4.10. `relacion_con_el_campo`

Explica qué papel cumple la sección dentro del campo atencional completo.

Ejemplo:

```yaml
relacion_con_el_campo: >
  Esta sección ayuda a que el campo no sea sólo informativo, sino analítico:
  enseña a ver la publicidad como arquitectura de mecanismos.
```

---

### 4.11. `audiencia_implicada`

Define para quién tiene sentido la sección.

Ejemplo:

```yaml
audiencia_implicada:
  - creadores de contenido
  - publicistas
  - emprendedores
  - personas interesadas en persuasión
  - estudiantes de marketing
```

---

### 4.12. `expectativa_recurrente`

Describe qué espera la audiencia cada vez que aparece la sección.

Ejemplo:

```yaml
expectativa_recurrente: >
  Cada pieza de esta sección debe revelar un mecanismo oculto, mostrarlo en
  funcionamiento y extraer una regla transferible.
```

La expectativa recurrente es lo que hace que una sección pueda convertirse en hábito atencional.

---

### 4.13. `temas_admisibles`

Lista temas que pueden entrar en la sección.

Ejemplo:

```yaml
temas_admisibles:
  - titulares
  - curiosidad
  - garantías
  - precio como señal
  - Barnum effect
  - mail order advertising
  - venta directa
  - historia de la publicidad
```

---

### 4.14. `realizaciones_compatibles`

Lista formatos en los que la sección puede materializarse.

Ejemplo:

```yaml
realizaciones_compatibles:
  - video_corto
  - carousel
  - video_largo
  - newsletter
  - clase
```

---

### 4.15. `frecuencia_o_ritmo`

Define la recurrencia de la sección.

Ejemplo:

```yaml
frecuencia_o_ritmo: semanal
```

O:

```yaml
frecuencia_o_ritmo: serie_abierta_no_periodica
```

---

### 4.16. `ejemplos_de_manifestaciones`

Lista piezas concretas posibles.

Ejemplo:

```yaml
ejemplos_de_manifestaciones:
  - realizacion: video_corto
    titulo: "El truco psicológico detrás de este anuncio antiguo"
  - realizacion: carousel
    titulo: "5 pasos para desmontar una campaña publicitaria"
  - realizacion: newsletter
    titulo: "Por qué esta garantía cambia la percepción de riesgo"
```

---

### 4.17. `riesgos_de_confusion`

Define confusiones comunes.

Ejemplo:

```yaml
riesgos_de_confusion:
  - confundir la sección con un tema
  - confundir la sección con una realización
  - convertir la sección en una categoría demasiado amplia
  - aceptar temas que no cumplen la operación de valor
```

---

### 4.18. `criterios_de_validacion`

Define cómo saber si la sección está bien construida.

Ejemplo:

```yaml
criterios_de_validacion:
  - la sección tiene una promesa de valor reconocible
  - puede contener varios temas
  - puede materializarse en varias realizaciones
  - excluye temas que no cumplen su operación
  - genera expectativa recurrente
  - no se reduce a una sola pieza
```

## 5. Prueba para distinguir sección, tema, realización y manifestación

### 5.1. Si responde “¿de qué trata?”, probablemente es tema

Ejemplos:

```txt
Historia de la publicidad
Barnum effect
Mail order
Precio como señal
Titulares
Venta directa
```

---

### 5.2. Si responde “¿qué tipo de valor recurrente entrega?”, probablemente es sección

Ejemplos:

```txt
Desmontajes de mecanismos
Principios antiguos aplicados hoy
Psicología del comprador
Laboratorio de anuncios
Estrategias por formato
Errores que enseñan
Casos convertidos en modelo
Diagnóstico de piezas
```

---

### 5.3. Si responde “¿en qué forma aparece?”, probablemente es realización

Ejemplos:

```txt
video_corto
carousel
newsletter
video_largo
hilo
clase
landing
```

---

### 5.4. Si responde “¿cuál es la pieza concreta?”, es manifestación

Ejemplos:

```txt
un video específico
un carousel específico
un newsletter específico
un guion específico
una clase específica
```

## 6. Tipos posibles de secciones

Las secciones pueden clasificarse por el tipo de valor que ofrecen.

---

### 6.1. Secciones de desmontaje

Revelan cómo funciona algo.

```yaml
tipo: seccion_de_desmontaje
operacion: descomponer_mecanismo
valor: comprensión interna de una pieza, fenómeno o estrategia
```

Ejemplos:

```txt
Desmontajes de mecanismos publicitarios
Anatomía de un anuncio
Por qué funcionó esta campaña
```

---

### 6.2. Secciones de aplicación

Toman un principio y muestran cómo usarlo.

```yaml
tipo: seccion_de_aplicacion
operacion: convertir_principio_en_accion
valor: utilidad práctica
```

Ejemplos:

```txt
Aplicaciones modernas de principios antiguos
Cómo usar esta regla en tu negocio
De la teoría al anuncio
```

---

### 6.3. Secciones de diagnóstico

Evalúan casos concretos.

```yaml
tipo: seccion_de_diagnostico
operacion: detectar_problema_y_causa
valor: comprensión de fallos y oportunidades
```

Ejemplos:

```txt
Diagnóstico de anuncios
Por qué tu mensaje no convierte
Errores invisibles en campañas
```

---

### 6.4. Secciones de comparación

Colocan dos o más elementos en contraste.

```yaml
tipo: seccion_de_comparacion
operacion: revelar_diferencias_y_equivalencias
valor: criterio comparativo
```

Ejemplos:

```txt
Antes vs ahora
Publicidad antigua, estrategia moderna
Lo que cambió con cada medio
```

---

### 6.5. Secciones de archivo o memoria

Organizan historia, casos y referencias.

```yaml
tipo: seccion_de_archivo
operacion: conservar_y_reinterpretar_casos
valor: memoria estructurada del campo
```

Ejemplos:

```txt
Archivo de anuncios históricos
Casos clásicos
Historia operativa de la publicidad
```

Importante: aquí “historia” puede formar parte de una sección, pero la sección no es simplemente “historia”. Su valor puede ser archivo, memoria, comparación o extracción de principios.

---

### 6.6. Secciones de principios

Extraen reglas generales.

```yaml
tipo: seccion_de_principios
operacion: abstraer_reglas_transferibles
valor: comprensión reusable
```

Ejemplos:

```txt
Principios que siguen vivos
Leyes de atención
Reglas de conversión
```

---

### 6.7. Secciones de laboratorio

Prueban, simulan o experimentan.

```yaml
tipo: seccion_de_laboratorio
operacion: experimentar_y_observar_resultados
valor: aprendizaje por prueba
```

Ejemplos:

```txt
Laboratorio de titulares
Pruebas de hooks
Experimentos de oferta
```

---

### 6.8. Secciones de traducción

Traducen un lenguaje, época o teoría a otra.

```yaml
tipo: seccion_de_traduccion
operacion: convertir_un_marco_en_otro
valor: hacer aplicable una idea en otro contexto
```

Ejemplos:

```txt
De Scientific Advertising a TikTok
Del mail order a las landing pages
De la teoría psicológica al anuncio concreto
```

---

## 7. Cómo un tema puede recorrer varias secciones

Un tema no pertenece necesariamente a una sola sección.

Ejemplo:

```txt
tema:
  Mail order advertising
```

Puede entrar en distintas secciones:

```txt
seccion:
  Principios antiguos, aplicaciones modernas

tratamiento:
  extraer reglas antiguas y aplicarlas a plataformas actuales.
```

```txt
seccion:
  Laboratorio de conversión

tratamiento:
  estudiar cómo el mail order medía respuesta, costo y retorno.
```

```txt
seccion:
  Evolución de formatos

tratamiento:
  comparar carta de venta, cupón, landing page y funnel moderno.
```

```txt
seccion:
  Desmontajes de mecanismos

tratamiento:
  descomponer una pieza de mail order en promesa, garantía, prueba y llamado.
```

El tema es el mismo, pero la sección cambia el valor producido.

---

## 8. Cómo una sección puede recorrer varias realizaciones

Una sección puede materializarse de muchas formas.

Ejemplo:

```txt
seccion:
  Desmontajes de mecanismos publicitarios

tema:
  Curiosidad publicitaria
```

Realizaciones posibles:

```txt
video_corto:
  explica un mecanismo en 30-60 segundos.

carousel:
  muestra pasos visuales del mecanismo.

video_largo:
  analiza varios casos y desarrolla el principio.

newsletter:
  explica el mecanismo con ejemplos, notas y aplicación.

clase:
  convierte el mecanismo en aprendizaje guiado.
```

La sección conserva su identidad, pero cada realización adapta la forma.

---

## 9. Relación con campos atencionales

Una sección cumple varias funciones dentro de un campo atencional:

```txt
1. segmenta la atención interna del campo;
2. estabiliza expectativas recurrentes;
3. organiza temas bajo una forma de valor;
4. permite continuidad editorial;
5. facilita pertenencia y reconocimiento;
6. puede adaptarse a varias realizaciones;
7. sirve como unidad de producción repetible;
8. ayuda a diseñar rutas de consumo dentro del campo.
```

El campo atencional no es sólo una suma de piezas. Es una arquitectura que organiza formas de atención. Las secciones son una de sus unidades intermedias más importantes.

---

## 10. Relación con realizaciones

La realización materializa una sección, pero no la agota.

```txt
seccion
  → puede tener muchas realizaciones

realizacion
  → puede servir a muchas secciones
```

Ejemplo:

```txt
seccion:
  Errores que enseñan

realizaciones:
  - video_corto
  - carousel
  - newsletter
  - clase
```

Y al revés:

```txt
realizacion:
  video_corto

puede materializar:
  - Desmontajes de mecanismos
  - Principios antiguos aplicados hoy
  - Laboratorio de titulares
  - Mitos publicitarios desmontados
```

Por eso, sección y realización no deben confundirse.

---

## 11. Relación con construcción conceptual

La construcción conceptual aporta temas, ideas activas, relaciones, contrastes y núcleos de sentido.

La sección organiza esa materia conceptual según una promesa de valor.

```txt
construccion_conceptual
  → aporta materia conceptual

seccion
  → decide qué tipo de valor se producirá con esa materia

realizacion
  → decide cómo se materializará ese valor
```

Ejemplo:

```txt
construccion_conceptual:
  ideas sobre precio como señal de valor

seccion:
  Psicología aplicada de la publicidad

realizacion:
  carousel

manifestacion:
  secuencia visual sobre cómo el precio altera percepción de calidad
```

## 13. Ejemplo completo 1: sección de desmontaje

```yaml
seccion:
  id: seccion_desmontajes_de_mecanismos_publicitarios
  nombre: Desmontajes de mecanismos publicitarios
  definicion: >
    Sección dedicada a descomponer piezas, campañas, técnicas o fenómenos
    publicitarios para mostrar el mecanismo que los hace funcionar.

  promesa_de_valor: >
    La audiencia aprende a ver la publicidad como una estructura compuesta
    por mecanismos, decisiones, efectos y principios transferibles.

  operacion_atencional: revelacion_analitica
  operacion_cognitiva: descomposicion_de_mecanismos

  criterio_de_inclusion_de_temas: >
    Entran temas que puedan descomponerse en mecanismo, intención,
    efecto, estructura o principio reutilizable.

  criterio_de_exclusion_de_temas: >
    No entran temas puramente anecdóticos si no se puede extraer de ellos
    una estructura o mecanismo.

  tipo_de_transformacion: >
    Convierte un fenómeno publicitario en una arquitectura comprensible,
    comparable y transferible.

  relacion_con_el_campo: >
    Fortalece la idea del campo como análisis estructural de la atención
    y la persuasión.

  audiencia_implicada:
    - creadores de contenido
    - publicistas
    - emprendedores
    - estudiantes de marketing
    - personas interesadas en persuasión

  expectativa_recurrente: >
    Cada pieza debe revelar un mecanismo oculto o poco evidente y mostrar
    cómo opera.

  temas_admisibles:
    - curiosidad publicitaria
    - titulares
    - garantías
    - Barnum effect
    - propiedad psicológica
    - mail order advertising
    - historia de la publicidad

  realizaciones_compatibles:
    - video_corto
    - carousel
    - video_largo
    - newsletter
    - clase

  frecuencia_o_ritmo: semanal

  ejemplos_de_manifestaciones:
    - realizacion: video_corto
      titulo: "El truco psicológico detrás de este anuncio antiguo"
    - realizacion: carousel
      titulo: "5 capas ocultas en un anuncio que parece simple"
    - realizacion: newsletter
      titulo: "Por qué esta garantía reduce el miedo a comprar"

  riesgos_de_confusion:
    - confundir la sección con una lista de temas
    - hacer piezas históricas sin desmontaje
    - producir ejemplos sin extraer mecanismo

  criterios_de_validacion:
    - cada pieza revela un mecanismo
    - cada tema se transforma en estructura
    - la audiencia recibe una regla o principio transferible
```

## 16. Relación entre secciones y programación editorial

Las secciones pueden organizar una programación editorial.

Ejemplo:

```txt
lunes:
  Principios antiguos, aplicaciones modernas

miércoles:
  Desmontajes de mecanismos

viernes:
  Laboratorio de anuncios

domingo:
  Archivo de casos
```

Esto convierte el campo en una entidad reconocible y recurrente.

La audiencia puede aprender a esperar distintos tipos de valor según la sección.

## 17. Relación entre sección y pertenencia

Una sección puede funcionar como punto de identificación para la audiencia.

Ejemplo:

```txt
seccion:
  Diagnóstico de piezas

efecto posible:
  "Esta sección es para personas como yo, que están intentando entender
  por qué sus anuncios no funcionan."
```

La sección no sólo organiza temas. También puede organizar pertenencia.

Una sección bien diseñada puede producir:

```txt
reconocimiento
hábito
expectativa
confianza
participación
sensación de lugar dentro del campo
```

## 18. Errores frecuentes

### Error 1: confundir sección con tema

Incorrecto:

```txt
seccion:
  Historia de la publicidad
```

Más preciso:

```txt
tema:
  Historia de la publicidad

seccion posible:
  Principios antiguos, aplicaciones modernas
```

---

### Error 2: confundir sección con realización

Incorrecto:

```txt
seccion:
  videos cortos
```

Más preciso:

```txt
realizacion:
  video_corto

seccion:
  Desmontajes de mecanismos
```

---

### Error 3: hacer una sección demasiado amplia

Incorrecto:

```txt
seccion:
  Marketing
```

Problema: no define una promesa de valor específica.

Más preciso:

```txt
seccion:
  Estrategias de conversión explicadas por casos
```

---

### Error 4: hacer una sección demasiado estrecha

Incorrecto:

```txt
seccion:
  El anuncio de Palmolive de 1923
```

Problema: eso es probablemente una manifestación o un caso, no una sección.

Más preciso:

```txt
tema:
  anuncio de Palmolive de 1923

seccion:
  Desmontajes de anuncios históricos
```

---

### Error 5: no definir operación de valor

Una sección sin operación de valor se vuelve una carpeta de temas.

Debe definirse:

```txt
qué hace la sección con los temas
qué espera recibir la audiencia
qué tipo de transformación produce
```

---

## 19. Checklist para crear una sección

```txt
[ ] La sección no es sólo un tema.
[ ] La sección no es una realización.
[ ] La sección puede contener varios temas.
[ ] La sección puede producir varias manifestaciones.
[ ] La sección tiene promesa de valor clara.
[ ] La sección tiene operación atencional definida.
[ ] La sección tiene operación cognitiva definida.
[ ] La sección tiene criterios de inclusión y exclusión.
[ ] La sección puede repetirse sin agotarse en una sola pieza.
[ ] La sección puede materializarse en varias realizaciones.
[ ] La audiencia puede reconocer qué tipo de valor recibe.
[ ] La sección contribuye al campo atencional completo.
```

---

## 20. Fórmula final

```txt
La sección no es el tema.
La sección es una forma recurrente de entregar valor dentro del campo.
Los temas son materiales que pueden ocupar esa sección.
Las realizaciones son formas materiales mediante las cuales esa sección aparece.
Las manifestaciones son piezas concretas producidas desde esa combinación.
```

Forma compacta:

```txt
campo_atencional
  → seccion
    → tema
      → realizacion
        → manifestacion
```

Forma funcional:

```txt
campo_atencional
  organiza la atención general.

seccion
  organiza una promesa recurrente de valor.

tema
  aporta materia conceptual.

realizacion
  aporta forma material.

manifestacion
  aparece como pieza concreta.
```

---

## 21. Definición sintética

Una sección es un **contenedor funcional, recurrente y reconocible** dentro de un campo atencional. Su función es organizar distintos temas bajo una misma promesa de valor, una misma operación atencional y una misma expectativa de consumo, permitiendo que esos temas se materialicen en distintas realizaciones sin perder coherencia dentro del campo.
