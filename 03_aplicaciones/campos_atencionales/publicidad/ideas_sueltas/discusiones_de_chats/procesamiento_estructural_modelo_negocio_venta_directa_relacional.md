# Síntesis estructural

```txt
El modelo detrás de empresas tipo Sheló, Betterware y Tupperware no debe
entenderse simplemente como “venta por catálogo”.

La estructura más profunda es:

empresa central
  → produce núcleo comercial
    → producto + marca + catálogo + incentivos + narrativa
      → afiliadas/distribuidoras
        → adaptan el núcleo al contexto local
          → publican, recomiendan, conversan, demuestran
            → activan campos atencionales personales
              → convierten confianza en ventas
                → convierten ventas en recompra
                  → convierten afiliación en expansión de red
                    → convierten datos en inteligencia
                      → convierten comunidad en infraestructura comercial

La empresa gana porque distribuye funciones que normalmente tendría que comprar,
contratar o controlar directamente:

- publicidad
- recomendación
- venta
- seguimiento
- entrega
- reclutamiento
- comunidad
- datos
- confianza

La afiliada gana o busca ganar porque accede a:

- margen
- descuentos
- comisiones
- recompensas
- identidad de emprendimiento
- pertenencia
- reconocimiento
- posible trayectoria de liderazgo

El modelo se sostiene cuando hay venta real, productos útiles, recompra,
confianza y cuidado de la red social.

El modelo se degrada cuando la presión, el reclutamiento o la promesa aspiracional
consumen la confianza que hacía posible la venta.
```

Resultado del procesamiento:

El modelo de estas empresas puede tratarse como una arquitectura donde:

empresa = núcleo productor de identidad y oferta
afiliada = adaptador humano local
red social = campo atencional de confianza
catálogo = calendario de activación

recompra = estabilizador económico
reclutamiento = mecanismo de multiplicación
logística = función distribuida
pagos/datos/digitalización = modernización del sistema
campo atencional derivado = oportunidad de profesionalización y monetización externa

La fórmula compacta es:

red social + producto + confianza + incentivo + adaptación local
