# Campos atencionales

Aplicación dedicada a diseñar entidades que convocan, organizan, sostienen y transforman atención mediante conocimiento, experiencia de contacto, pertenencia y producción recurrente.

## Subáreas

- `modelos`: arquitecturas provisionales para construir el backend cognitivo, el frontend psicológico, la pertenencia racionalizada y mecanismos psicológicos aplicados de un campo.

Estos documentos pueden reutilizar capacidades del núcleo y métodos transversales, pero sus objetivos de audiencia, participación, conversión y monetización los mantienen en la capa de aplicación.

## Papel dentro del artefacto integral

- **Función:** diseñar sistemas que convocan, organizan, sostienen y transforman atención de manera recurrente.
- **Entradas:** conocimiento estructurado, audiencia, mecanismos psicológicos, canales, secciones, objetivos y restricciones éticas.
- **Salidas:** modelos de backend/frontend, pertenencia, recorridos, interfaces y circuitos de retroalimentación.
- **Consumidores:** creación de contenido, diseño de comunidades, publicidad y experimentos de interacción.
- **Límite:** los modelos son provisionales y contextuales; no deben presentarse como psicología universal ni como arquitectura canónica.
