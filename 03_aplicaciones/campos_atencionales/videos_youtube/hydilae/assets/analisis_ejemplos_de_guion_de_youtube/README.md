# Módulo aplicado: `analizador_argumentativo`

Esta carpeta reúne la primera pasada de análisis de los guiones contenidos en
`ejemplos_de_guion_de_youtube`.

## Organización

Cada subcarpeta corresponde a un guion y contiene:

1. una copia exacta del archivo original disponible al iniciar el análisis;
2. `analisis_argumentativo.md`, elaborado con el módulo
   `ART_modelo_arquitectura_macro_narrativo_cognitiva/analizador_argumentativo`.

## Criterio de análisis

El objeto del análisis no es únicamente el tema de cada video, sino su
arquitectura de justificación:

- qué tesis intenta volver aceptable;
- mediante qué `grounds` o apoyos;
- con qué `warrants` o garantías, incluso cuando permanecen implícitas;
- qué respaldo, matices y objeciones incorpora;
- qué esquemas argumentativos utiliza;
- cómo distribuye la argumentación en movimientos narrativo-cognitivos;
- dónde se encuentran su fuerza y sus vulnerabilidades.

La unidad mínima considerada es el **movimiento argumentativo**, no la oración
aislada. Los segmentos promocionales se excluyen del argumento principal. Si
una transcripción contiene duplicaciones o problemas de codificación, se
conservan en la copia original y se documentan en el alcance del análisis.

NOTAS PERSONALES:
Prompt del nuevo proyecto

En este proyecto hay muchos ejemplos de guiones de videos que han tenido éxito. Si bien es importante reconocer que el éxito de un video no depende únicamente de la dimensión textual, sino de muchos otros, como la oratoria, la música y la parte visual, el guion es un factor sumamente importante en el éxito de un video.

En este proyecto nos enfocaremos exclusivamente en la parte textual del video: en el guion.

Los guiones contienen información que puede ser de gran utilidad para el desarrollo de otros guiones, por ejemplo:

- Nos permiten entender cómo desarrollar las ideas para un tema en particular: cómo presentar un concepto, cómo abrir una interrogante, el ritmo, el orden, la prioridad.
- Nos permite igualar el vocabulario. Al comprender éste es posible llegar a audiencias similares.
- Permite generar ideas nuevas a partir de las ideas que se encuentran en los guiones.
- Permite analizar canales enteros al estudiar su contenido, lo cual facilitaría replicar lo que ya tiene éxito.
- Podría ayudar a comprender los mecanismos de recomendación que usan los algoritmos.

Este método requiere comprender los guiones a un nivel estructural, no sólo lingüístico. Se busca extraer la estructura que conforma al guion.

Los módulos del MAANC son de mucha utilidad para esto, puesto que permiten extraer la estructura desde distintos puntos de vista.

Cada ejemplo debe verse desde dos enfoques distintos:

1. Como una manifestación lingüística.
2. Como una estructura compuesta de distintas piezas.

Ambos enfoques tienen una aplicación distinta:

Cuando se le mira como una manifestación lingüística es posible crear una interfaz humana, lo cual funciona como puente cognitivo entre el sistema IA y el humano.

Al verlo como estructura se tiene que cada guion puede verse como un sistema con un fin particular, el cual tiene un funcionamiento particular y piezas que cumplen funciones específicas, ideal para emular sistemas informáticos, es decir: sistemas cognitivos.
