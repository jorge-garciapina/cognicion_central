# Arquitectura argumentativa — MOV_05

## 0. Identidad del movimiento

```yaml
movimiento:
  id: MOV_05
  nombre: forma_interna_de_la_frase_barnum
  tipo:
    - refinamiento_del_mensaje_barnum
    - analisis_de_forma
    - explicacion_de_alta_aplicabilidad
  funcion_narrativo_cognitiva: >
    Explicar qué forma debe tener la frase Barnum para que pueda ser completada
    por el receptor como si describiera algo propio, singular o íntimo.
```

## 1. Posición en la arquitectura total

```txt
MOV_01:
  caso / entrada narrativa

MOV_02:
  partes internas del mecanismo

MOV_03:
  juego estratégico

MOV_04:
  condición de validación de la frase:
    marco, respaldo, método o escena interpretativa

MOV_05:
  forma de la frase:
    alta aplicabilidad, tensión común, ambigüedad y apertura autobiográfica
```

## 2. Claim dominante

```yaml
claim_dominante:
  id: CL_MOV_05_GLOBAL
  formulacion: >
    La frase Barnum funciona cuando adopta la forma de un enunciado de alta
    aplicabilidad: toca tensiones comunes, describe situaciones ampliamente
    compartidas, mantiene ambigüedad suficiente para permitir completado
    autobiográfico y aprovecha el contexto para parecer más específica de lo
    que realmente es.
  tipo: claim_definicional_funcional
  funcion: >
    Definir la forma verbal del mensaje_barnum como artefacto diseñado para
    producir reconocimiento subjetivo.
```

## 3. Problema que resuelve

```yaml
problema_argumentativo:
  formulacion: >
    MOV_04 explicó por qué la frase necesita respaldo. MOV_05 explica qué
    debe tener la frase en sí misma para que ese respaldo no sostenga una
    afirmación vacía, sino una forma capaz de activar asociaciones personales.
```

## 4. Grounds

```yaml
grounds:
  - id: GR_MOV_05_01
    tipo: ground_conceptual
    contenido: >
      Las frases Barnum usan contenidos de alta frecuencia humana:
      inseguridad, deseo de reconocimiento, potencial no realizado, tensión
      entre independencia y necesidad de aprobación, dudas sobre el futuro,
      cansancio, contradicción interna o búsqueda de sentido.

  - id: GR_MOV_05_02
    tipo: ground_formal
    contenido: >
      La frase evita detalles demasiado verificables y deja espacios para que
      el receptor introduzca su propia biografía.

  - id: GR_MOV_05_03
    tipo: ground_contextual
    contenido: >
      El contexto puede volver más específica una frase general al orientar
      qué asociaciones debe activar el receptor.
```

## 5. Warrant

```yaml
warrant:
  id: WA_MOV_05_01
  formulacion: >
    Si una frase activa una tensión común y deja abierto el modo exacto en que
    esa tensión debe completarse, entonces muchos receptores pueden encontrar
    en ella una conexión autobiográfica suficiente para sentirla personal.
  tipo: warrant_psicologico_asociativo
```

## 6. Backing

```yaml
backing:
  id: BK_MOV_05_01
  formulacion: >
    Las descripciones Barnum suelen apoyarse en generalidad, ambigüedad,
    relevancia aparente, formulaciones favorables o equilibradas y rasgos
    comunes que muchas personas pueden reconocer como propios.
```

## 7. Componentes de la forma Barnum

```yaml
forma_barnum:
  1_alta_aplicabilidad:
    funcion: >
      Asegurar que la frase pueda ser reconocida por muchas personas.
    recursos:
      - tensiones_humanas_comunes
      - experiencias_frecuentes
      - estados_emocionales_generales

  2_ambiguedad_controlada:
    funcion: >
      Permitir que el receptor complete lo no dicho.
    recursos:
      - expresiones_no_cuantificadas
      - temporalidad_amplia
      - causas_abiertas
      - sujetos_indeterminados

  3_apariencia_de_especificidad:
    funcion: >
      Hacer que la frase parezca más individual de lo que es.
    recursos:
      - segunda_persona
      - vocabulario_diagnostico
      - referencia_a_conflictos_internos
      - tono_de_lectura_personal

  4_resonancia_emocional:
    funcion: >
      Activar una zona de importancia subjetiva.
    recursos:
      - deseo
      - miedo
      - frustracion
      - potencial
      - contradiccion
      - necesidad_de_reconocimiento

  5_aprovechamiento_del_contexto:
    funcion: >
      Orientar la interpretación sin volver la frase demasiado específica.
    recursos:
      - situacion_del_receptor
      - canal
      - problema_declarado
      - expectativa_creada_por_MOV_04
```

## 8. Qualifiers

```yaml
qualifiers:
  - id: QL_MOV_05_01
    formulacion: >
      Alta aplicabilidad no significa máxima vaguedad. Si la frase es demasiado
      vacía, el receptor puede descartarla.

  - id: QL_MOV_05_02
    formulacion: >
      La frase no debe ser tan específica que pueda fallar fácilmente, ni tan
      general que pierda toda fuerza psicológica.

  - id: QL_MOV_05_03
    formulacion: >
      La forma Barnum no opera sola: gana fuerza cuando está sostenida por el
      marco de validación explicado en MOV_04.
```

## 9. Rebuttals

```yaml
rebuttals:
  - id: RB_MOV_05_01
    objecion: >
      Si la frase aplica a muchas personas, entonces debería ser obvio que no
      describe a nadie en particular.
    respuesta: >
      No necesariamente. La frase puede ser general en su contenido, pero sentirse
      personal cuando el receptor la completa con detalles propios.

  - id: RB_MOV_05_02
    objecion: >
      Una frase común no debería producir sensación de diagnóstico.
    respuesta: >
      La sensación de diagnóstico aparece cuando la frase común se presenta con
      respaldo interpretativo y activa asociaciones autobiográficas relevantes.
```

## 10. Salida cognitiva del movimiento

```yaml
salida_cognitiva:
  antes: >
    El espectador entiende que la frase necesita un marco de validación.

  despues: >
    El espectador entiende que la frase debe tener una forma específica:
    amplia, ambigua, emocionalmente resonante, contextualizable y abierta al
    completado autobiográfico.
```

```txt
tension_humana_comun
  + ambiguedad_controlada

          → reconocimiento_subjetivo
```
