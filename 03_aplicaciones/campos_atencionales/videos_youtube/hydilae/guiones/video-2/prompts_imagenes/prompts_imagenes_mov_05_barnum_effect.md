# Prompts de imágenes para MOV_05 — Efecto Barnum

## Propósito del documento

Este documento organiza las descripciones visuales del **MOV_05** del guion sobre el efecto Barnum en formato de prompts de generación de imágenes.

Cada imagen está asociada a una parte específica del guion y se presenta con:

- fragmento exacto del guion,
- momento de entrada,
- palabras aproximadas cubiertas,
- tipo de imagen,
- función visual,
- prompt de generación.

La lógica visual del MOV_05 se centra en mostrar que, después de comprender el **marco de validación** en MOV_04, ahora corresponde analizar la **forma interna de la frase Barnum**.

```txt
MOV_04 explicó el marco externo.
MOV_05 explica la forma interna de la frase.
```

La idea dominante de MOV_05 es:

```txt
Una frase Barnum no funciona sólo porque sea vaga.
Funciona porque tiene una arquitectura verbal calibrada:
  alta aplicabilidad
  + ambigüedad controlada
  + apariencia de especificidad
  + resonancia emocional
  + espacio para completado autobiográfico.
```

---

# Parámetros visuales generales para MOV_05

Usar esta base en todos los prompts:

```txt
Formato 16:9, estilo pixel art cinematográfico, composición clara, estética de ensayo visual psicológico, adultos solamente, sin niños ni adolescentes, iluminación dramática pero legible, fondo oscuro o neutro, símbolos visuales claros, texto grande y legible, evitar saturación, evitar texto pequeño, evitar tono cómico, evitar caricatura infantil, no representar el efecto como magia, no representar al receptor como tonto, no usar marcas reales.
```

## Gramática visual recomendada para MOV_05

El MOV_05 debe usar una gramática visual más técnica que MOV_01 y MOV_02. Ya no se trata principalmente de narrar vidas concretas ni sólo de mostrar procesos psicológicos internos. Ahora se trata de **diseccionar una frase**.

Símbolos visuales recomendados:

```txt
laboratorio de frases
mesa de análisis
molde verbal
piezas de rompecabezas
huecos dirigidos
diales de calibración
tensiones internas
mapas emocionales
comparación entre versiones
fórmula final
```

La regla visual central es:

```txt
La frase Barnum debe verse como un artefacto verbal:
no contiene datos personales,
pero está diseñada para que el receptor pueda poner dentro su propia biografía.
```

# [MOV_05 | UG_05 | B05_01] Presentar frase como artefacto

**Función del beat:** presentar la frase Barnum como un artefacto verbal calibrado, no como simple vaguedad.

**Tratamiento recomendado:** progresión de 5 imágenes.

**Idea visual dominante:** pasar de “frase vaga” a “estructura diseñada”.

---

## Imagen 1 — La frase Barnum no es sólo vaga

### Fragmento exacto del guion

```txt
Una frase Barnum no es sólo una frase vaga.
```

### Cuándo entra

Justo al comenzar MOV_05.

### Palabras cubiertas

9 palabras aproximadamente.

### Tipo de imagen

Imagen de laboratorio conceptual.

### Función visual

Separar desde el inicio “Barnum” de “simple vaguedad”. La imagen debe decir visualmente que estamos entrando en una anatomía del mensaje, no en otra escena narrativa.

### Prompt de generación

```txt
Genera una imagen en formato 16:9, estilo pixel art cinematográfico. Fondo oscuro de laboratorio conceptual. En el centro hay una mesa de análisis iluminada desde arriba. Sobre la mesa aparece una frase convertida en objeto físico, como una tarjeta mecánica o pieza verbal. A un lado de la mesa hay una etiqueta tachada que dice “frase vaga”. Al otro lado, sobre la pieza central, aparece una etiqueta grande y clara: “Frase Barnum”. La imagen debe mostrar que una frase Barnum no es simplemente una frase vaga, sino un artefacto verbal con estructura. Usar lupa, regla, pinzas simbólicas y líneas de medición. Sin niños, sin adolescentes, sin estilo cómico.
```

Fondo oscuro, composición clara, sin niños, sin adolescentes.
