# Prompts de generación de imágenes — MOV_06 Barnum Effect

## Propósito del documento

Este documento organiza las imágenes propuestas para el **MOV_06** del guion sobre el efecto Barnum. Cada imagen está asociada a una parte específica del guion y se presenta con:

- fragmento exacto del guion,
- momento de entrada,
- palabras aproximadas cubiertas,
- tipo de imagen,
- función visual,
- prompt de generación.

La lógica visual del **MOV_06** se centra en mostrar que el patrón Barnum conserva su estructura aunque cambie de entorno.

```txt
mismo mecanismo
→ distintos entornos
→ mismas invariantes
→ diferentes superficies visuales
```

La idea dominante de MOV_06 es:

```txt
El patrón conserva identidad aunque cambie el escenario.
```

MOV_06 no debe sentirse como una lista de ejemplos. Debe sentirse como una **prueba de portabilidad**: el espectador debe reconocer que tarot, comunidades digitales, quizzes, venta, publicidad o política pueden funcionar como variaciones contextuales de una misma arquitectura.

La regla visual central es:

```txt
No mostrar “muchos temas”.
Mostrar “una misma estructura cambiando de piel”.
```

---

## Nota estructural sobre el MOV_06

En el guion actual, MOV_06 no contiene beats desarrollados como **B06_04**, **B06_05** ni **B06_06**. El documento pasa de:

```txt
B06_03 — Esoterismo / tarot
```

a:

```txt
B06_07 — Comunidad digital
```

y luego:

```txt
B06_08 — Comparación final
```

Por eso este documento trabaja con los beats existentes del guion y no inventa fragmentos hablados inexistentes. Las aplicaciones omitidas quedan sugeridas en imágenes de portabilidad, matriz o tablero general.

---

# Parámetros visuales generales para MOV_06

Usar como base en todos los prompts:

```txt
Formato 16:9, estilo pixel art cinematográfico, estética de ensayo visual psicológico, composición clara, adultos solamente, sin niños ni adolescentes, iluminación dramática pero legible, fondo oscuro o neutro, símbolos visuales claros, texto grande y legible, evitar saturación, evitar texto pequeño, evitar tono cómico, evitar caricatura infantil, no representar el mecanismo como control absoluto, no representar a los receptores como tontos, no usar marcas reales, no usar logos reales de YouTube ni de plataformas existentes.
```

Cuando el prompt pida texto dentro de la imagen, conviene que sea poco texto y muy grande. Si el generador falla con letras, se puede generar la imagen sin texto y añadir el texto después en edición.

# [MOV_06 | UG_06 | B06_01] Recordar juego + marco + forma

## Imagen 1 — Primera capa: juego

### Fragmento exacto del guion

```txt
Primero, hay un juego en el que los participantes son el emisor y receptor, y los resultados posibles son reconocimiento o descarte.
```

### Cuándo entra

Justo al comenzar MOV_06, cuando la voz dice:

```txt
“Primero, hay un juego...”
```

### Palabras cubiertas

21 palabras aproximadamente.

### Tipo de imagen

Infografía de recapitulación.

### Función visual

Recuperar MOV_03 sin volver a desarrollarlo. Debe recordar que el patrón tiene jugadores y salidas.

### Prompt de generación

```txt
Genera una imagen en formato 16:9, estilo pixel art cinematográfico e infografía conceptual. Fondo oscuro de tablero analítico. En el centro hay una tarjeta grande titulada “JUEGO”. Dentro de la tarjeta aparece un diagrama claro: “Emisor → Mensaje → Receptor”. Desde el receptor salen dos caminos: uno hacia “reconocimiento” y otro hacia “descarte”. El emisor y el receptor deben ser figuras adultas simples, no personajes concretos. Las flechas deben ser claras y luminosas. La imagen debe sentirse como una recapitulación del modelo estratégico, no como una escena narrativa. Texto grande y legible, sin niños, sin adolescentes, sin tono cómico.
```
