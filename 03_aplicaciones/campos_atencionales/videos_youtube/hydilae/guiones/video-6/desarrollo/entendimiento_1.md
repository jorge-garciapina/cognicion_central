# 2 RAMIFICACIONES PRODUCTO DE LAS IDEAS CONTENIDAS EN EL PROMPT

## RAMIFICACIÓN 1: IDEAS SOBRE EL VIDEO PRINCIPAL

1. A PARTIR DE LO QUE AQUÍ SE MUESTRA ES POSIBLE IMAGINAR NO SÓLO EL GUIÓN DE UN VIDEO, SINO UNA CONTELACIÓN DE CONTENIDO EN DISTINTOS FORMATOS. EL TEMA DE LOS SÍMBOLOS ES MUY AMPLIO Y VALE LA PENA EXTENDERLO
2. EL VIDEO PRINCIPAL DEBE SER UNA EXPLICACIÓN GENERAL DEL TEMA, EL CUAL DEBE MOSTRAR UN CAMPO LINGÜÍSTICO Y UN CAMPO SIMBÓLICO. LA TESIS PRINCIPAL DEBE SER INFORMATIVA: USARÁ COMO BASE EL ARTÍCULO DE COLLINS PARA EXPLICAR LOS CAMPOS LINGÜÍSTICOS, DEFINIRÁ: "CONCEPTO", "NODO", "LINK", "SIGNIFICADO" (Meaning in Quillian's theory), "CATEGORIZACIÓN", "ACTIVATION SPREADING" (ESTE SE DEBE USAR PARA EJEMPLIFICAR). ESTOS CONCEPTOS DEBEN SERVIR COMO PUNTO DE PARTIDA PARA HACER ANALOGÍAS CON LA RED SIMBÓLICA.
   - FUEGO
     → produce calor
     → produce luz
     → requiere combustible
     → puede quemar
     → puede destruir
     → se encuentra en una casa
     → forma parte de una chimenea
3. EL CAMPO SIMBÓLICO USARÁ LA MISMA ESTRUCTURA QUE YA PREPARÓ EL ESTUDIO DE LA RED SEMÁNTICA. USARÁ EL EJEMPLO QUE SE DA AL INICIO DEL JOVEN Y LA VELA, PERO SE ANALIZARÁ DESDE EL CAMPO. LO IMPORTANTE ES MOSTRAR LAS CONEXIONES QUE EXISTEN ENTRE LAS DISTINTAS "DIMENSIONES" QUE SE PRESENTAN EN LA SECUENCIA (ES NECESARIO DEFINIR CLARAMENTE ESTAS DIMENSIONES PARA QUE SEA MÁS FÁCIL DESCRIBIRLAS), Y EXPLICAR QUÉ ES LO QUE SE QUIERE MOSTRAR CON CADA DIMENSIÓN, ES DECIR, CUÁLES CONEXIONES HUMANAS SE BUSCA ACTIVAR.
   - Una interpretación simbólica es una configuración temporal de activación que integra relaciones perceptivas, conceptuales, analógicas, autobiográficas, afectivas y culturales.
   - VELA: encenderse, arder, consumirse,→ extinguirse
     PERSONA: juventud, maduración, envejecimiento, desaparición
     La interpretación aparece cuando ambas rutas encuentran intersecciones: duración, desgaste, tiempo, finitud, extinción, muerte

4. LO IMPORTANTE DEL VIDEO ES MOSTRAR UN MECANISMO COGNITIVO, QUE SE ENTIENDA QUE LO SIMBÓLICO Y LO LINGÜÍSTICO FUNCIONAN MEDIANTE ASOCIACIONES.

- AMBOS CASOS: No se limita a conectar palabras con otras palabras. Tampoco consiste en que un objeto tenga escondido un significado único. El significado aparece cuando una forma perceptible activa una red y, dentro de esa red, determinadas conexiones adquieren coherencia en un contexto específico.
