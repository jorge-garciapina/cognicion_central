# AP_23_SUB_02 — No se puede decir que sea así

> Nodo padre: [[AP_23 — Fórmula sobre la conciencia|AP_23]]


**Texto íntegro del guion utilizado**

```txt
“Que mi conciencia sea así. Que mi conciencia no sea así.”
```

**Función local**  
Aplica criterio de control.

**Intención sobre el espectador**  
Cerrar posibilidad de dominio soberano.

**Asociaciones por capas**

- **Semánticas:** conciencia, así, no así
- **Emocionales:** frustración, límite, desapego
- **Autobiográficas / fenomenológicas:** querer estar atento siempre
- **Visuales / audiovisuales:** texto sobre mente fluctuante
- **Argumentativas:** prueba de no-control

**Núcleo común**  
Conciencia no obedece mandato.

**Activación cognitiva esperada**  
`mandato → falla.`

**Riesgo de lectura**  
Necesita ejemplos claros.
