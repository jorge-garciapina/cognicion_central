# AP_10 — Forma / cuerpo / materia

## 1. Texto íntegro del guion utilizado

```txt
El sermón comienza hablando de la forma, lo físico, el cuerpo, la materia. La primera gran confusión de la que se habla sin decirla es que asociamos al Yo con el cuerpo, pero Buddha afirma la forma no es el “Yo”. Si la forma fuera el Yo, entonces se podría decir “que mi forma sea así. Que mi forma no sea así”, pero eso es imposible.
```

## 2. Tipo de componente

```yaml
- primer_agregado
- descarte_de_Rupa
- identificacion_corporal
```

## 3. Función dentro de la arquitectura macro

Abre la aplicación de la matriz del sermón con el candidato identitario más inmediato: el cuerpo.

## 4. Función dentro del apartado local

Dentro del recorrido de agregados, establece la estructura: candidato → criterio → falla.

## 5. Intención sobre el espectador

Busca que el espectador cuestione la identificación más evidente: “yo soy mi cuerpo”.

## 6. Asociaciones cognitivas por capas

**Semánticas:**


**Emocionales:**

```txt

```

**Argumentativas:**


## 7. Núcleo común con otros componentes

## 8. Activación cognitiva esperada

```txt
cuerpo → identificación ordinaria → no obedece → no-Yo.
```

## 9. Riesgo de lectura

Puede parecer desprecio del cuerpo si no se aclara que el cuerpo es real, pero no Yo.
