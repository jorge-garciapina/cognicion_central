# AP_26_SUB_03 — Cuerpo real, no eres cuerpo

> Nodo padre: [[AP_26 — Aclaración anti-nihilista|AP_26]]


**Texto íntegro del guion utilizado**

```txt
el cuerpo es real, pero no eres el cuerpo
```

**Función local**  
Frase eje de desidentificación corporal.

**Intención sobre el espectador**  
Hacer memorable el matiz.

**Asociaciones por capas**

- **Semánticas:** cuerpo, real, no eres
- **Emocionales:** desapego, extrañeza, alivio
- **Autobiográficas / fenomenológicas:** mirar el cuerpo sin serlo
- **Visuales / audiovisuales:** espejo con cuerpo y sombra Yo separada
- **Argumentativas:** anti-nihilismo aplicado a Rūpa

**Núcleo común**  
Realidad sin apropiación.

**Activación cognitiva esperada**  
`cuerpo existe → no soy cuerpo.`

**Riesgo de lectura**  
Puede sonar dualista.
