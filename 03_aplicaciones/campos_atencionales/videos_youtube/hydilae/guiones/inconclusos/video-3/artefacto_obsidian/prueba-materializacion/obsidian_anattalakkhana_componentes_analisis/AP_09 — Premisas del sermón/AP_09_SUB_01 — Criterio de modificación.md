# AP_09_SUB_01 — Criterio de modificación

> Nodo padre: [[AP_09 — Premisas del sermón|AP_09]]


**Texto íntegro del guion utilizado**

```txt
“Si algo es el Yo, entonces puedes modificarlo”
```

**Función local**  
Instala criterio de control.

**Intención sobre el espectador**  
Hacer intuitiva la relación entre Yo y soberanía.

**Asociaciones por capas**

- **Semánticas:** modificar, control, Yo
- **Emocionales:** poder, expectativa, frustración potencial
- **Autobiográficas / fenomenológicas:** intentar cambiar cuerpo o mente
- **Visuales / audiovisuales:** mano moldeando arcilla
- **Argumentativas:** criterio de descarte

**Núcleo común**  
Control como prueba del Yo.

**Activación cognitiva esperada**  
`Yo → modificar → control.`

**Riesgo de lectura**  
Debe precisarse control soberano.
