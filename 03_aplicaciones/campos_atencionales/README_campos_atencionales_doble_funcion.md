# README — Doble función de los archivos `.md` en `/campos_atencionales`

**Propósito del README:** describir cómo cada archivo Markdown de `/campos_atencionales` puede operar con una doble función dentro de la arquitectura ACCD.

La carpeta `/campos_atencionales` debe leerse como una zona de investigación y abastecimiento conceptual. Sus documentos pueden alimentar el diseño estructural de campos atencionales, pero también pueden convertirse en el contenido temático de un campo.

## Regla general de doble lectura

```txt
archivo.md
  ├─ lectura estructurante
  │   → ¿Qué principio, mecanismo, sección, señal, patrón o regla de diseño aporta para construir un campo atencional?
  │
  └─ lectura temática
      → ¿De qué podría tratar un campo atencional si este archivo se toma como construcción conceptual o núcleo temático?
```

## Diferencia entre las dos funciones

| Función | Pregunta que responde | Uso dentro de la arquitectura |
|---|---|---|
| **Función estructurante** | ¿Cómo ayuda este documento a diseñar la estructura de un campo atencional? | Aporta mecanismos, secciones, principios, señales, criterios de segmentación, reglas de confianza, patrones psicológicos o formas de conversión. |
| **Función temática** | ¿Sobre qué podría tratar el campo si este documento se toma como tema? | Aporta ideas activas, núcleos conceptuales, relaciones, ejemplos, contrastes, series temáticas y contenido cercano a una `construccion_conceptual`. |

## Síntesis operativa

La misma biblioteca puede usarse de dos modos complementarios:

```txt
modo_estructurante:
  documentos → principios de diseño → arquitectura del campo → secciones/protocolos/realizaciones

modo_tematico:
  documentos → ideas activas → construcción conceptual → series/piezas/campos temáticos
```

En modo estructurante, los archivos ayudan a diseñar **cómo debe existir** un campo atencional. En modo temático, ayudan a definir **de qué tratará** un campo atencional. La potencia de `/campos_atencionales` está en que muchos documentos pueden cumplir ambas funciones al mismo tiempo.
