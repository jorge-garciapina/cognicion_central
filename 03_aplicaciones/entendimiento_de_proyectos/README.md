# Entendimiento de proyectos

Aplicaciones que sintetizan cómo un proyecto interpreta una idea o estructura compartida.

## Contenido

- `# CNode cappspov-entendimiento-proy.txt`: cApp `pov-entendimiento-proyecto@1.0.0`; recibe contexto, POV e identificador de idea y produce un único `POVSynopsis` con matriz y procedencia.

## Estado y reglas de admisión

El archivo se conserva como `WORKING`: aunque declara `status: stable`, contiene un `+` residual en la lista de invariantes y requiere validación de sintaxis y ejecución antes de considerarse estable en COGNICION_CENTRAL.

Ingresan aquí cApps cuyo objetivo sea comprender o sintetizar la perspectiva de un proyecto. Las comparaciones entre varios proyectos requieren una aplicación o proceso distinto.

## Papel dentro del artefacto integral

- **Función:** sintetizar cómo un proyecto específico entiende una idea compartida sin mezclar su punto de vista con el de otros proyectos.
- **Entradas:** contexto del proyecto, POV, identificador de idea y procedencia disponible.
- **Salidas:** una sinopsis estructurada con matriz de afirmaciones y trazabilidad.
- **Consumidores:** comparación posterior, coordinación interproyecto y procesos de decisión contextual.
- **Límite:** el estado actual es `WORKING`; una sinopsis no sustituye las fuentes ni constituye consenso entre proyectos.
