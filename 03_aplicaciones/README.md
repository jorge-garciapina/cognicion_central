# 03_aplicaciones

Adaptaciones de COGNICION_CENTRAL a objetivos concretos.

Cada aplicación debe declarar propósito, entradas, salidas, memoria, permisos, dependencias, validación y relación con el núcleo. Una aplicación no define por sí sola la identidad del sistema general.

## Aplicaciones

- `aprendizaje_estructural`: aplicación pedagógica y sus realizaciones.
- `busqueda_cognitiva`: localización estructura-a-estructura dentro de portadores del conocimiento.
- `creacion_de_contenido`: producción de guiones, escenas, formatos y recursos expresivos.
- `campos_atencionales`: diseño de entidades, pertenencia y circuitos recurrentes de atención.
- `company_code`: ciclo aplicado de generación, análisis y materialización de artefactos de proyectos de software.
- `entendimiento_de_proyectos`: cApps para sintetizar el punto de vista de un proyecto sobre una idea compartida.

## Papel dentro del artefacto integral

- **Función:** convertir capacidades transversales en sistemas orientados a una necesidad, dominio o resultado concreto.
- **Entradas:** núcleo, métodos, contexto pertinente, permisos y objetivos humanos.
- **Salidas:** configuraciones, procesos, modelos y decisiones operativas específicas.
- **Consumidores:** usuarios finales, casos de validación, procesos productivos y artefactos generados.
- **Límite:** una aplicación usa COGNICION_CENTRAL, pero no redefine por sí sola la identidad ni la autoridad del sistema completo.
