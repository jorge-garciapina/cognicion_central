# Referencias de estilo

Esta carpeta conserva corpus, análisis y artefactos que describen una voz de escritura aplicable a la producción de contenido.

## Contenido

- `ART_estilo_de_escritura_sesion_1.txt`: artefacto NDJSON con diario, estudio estilístico, guion y metadatos de una sesión de optimización de escritura.

## Función y uso

Estos documentos sirven para recuperar rasgos de voz, ritmo, imágenes, operaciones retóricas y riesgos de imitación. No constituyen reglas universales de COGNICION_CENTRAL ni sustituyen el canon, el protocolo de la aplicación o las instrucciones actuales del humano.

Al usar un artefacto `ART_`, primero deben identificarse sus registros internos y recuperarse sólo los que sean pertinentes para la tarea. La presencia de una copia interna de una herramienta o un guion no convierte el artefacto completo en fuente vigente de esos componentes.

## Admisión

Ingresan aquí estudios de voz, corpus autorizados, guías estilísticas y sesiones de análisis vinculadas a creación de contenido. Los métodos de análisis reutilizables en otros dominios pertenecen a `02_metodos_y_herramientas`.

## Papel dentro del artefacto integral

- **Función:** aportar memoria recuperable de voz, ritmo, recursos retóricos y decisiones estilísticas autorizadas.
- **Entradas:** corpus, sesiones de escritura, análisis, guiones y metadatos de procedencia.
- **Salidas:** rasgos de estilo, ejemplos, restricciones y señales para adaptar nuevas piezas.
- **Consumidores:** creación de contenido, guionización y procesos de revisión de voz.
- **Límite:** una referencia orienta; no autoriza imitación indiscriminada ni prevalece sobre el comando actual, el canon o las fuentes de contenido.
