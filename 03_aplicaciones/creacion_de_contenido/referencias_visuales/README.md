# Referencias visuales de creación de contenido

Documentos visuales del video 4 y métodos asociados a secuencias de imágenes.

## Unidad relacionada

`EC06.pdf`, `EC07.pdf`, `EC10.pdf`, `EC12.pdf` y `theme_visual_video_4.pdf` deben recuperarse conjuntamente cuando la tarea afecte la continuidad visual del video 4. `secuencia_de_imagenes.pdf` define una técnica visual reutilizable.

Estos PDF son realizaciones pesadas; deben cargarse de manera selectiva por página o sección.

## Papel dentro del artefacto integral

- **Función:** conservar continuidad, decisiones y técnicas visuales necesarias para reconstruir o extender producciones específicas.
- **Entradas:** piezas visuales, temas, secuencias, parámetros de producción y decisiones de una realización.
- **Salidas:** referencias comparables, restricciones de continuidad y ejemplos de técnica visual.
- **Consumidores:** producción audiovisual, revisión de consistencia y nuevas realizaciones relacionadas.
- **Límite:** una referencia concreta no es una regla visual universal; su peso depende de la tarea, versión y unidad de producción.
