# Composición ascendente en historias

**Tipo de documento:** modelo conceptual autónomo  
**Estado:** provisional, integrable a memoria de ideas  
**Familia probable:** modelo / método / nodo conceptual  

---

## 0. Propósito

Este documento formaliza la intuición de que las historias pueden construirse mediante **composición ascendente**: unidades pequeñas con función narrativa se combinan para formar unidades mayores.

La composición ascendente permite pensar la historia no como un bloque indivisible, sino como una arquitectura ensamblada por niveles.

---

## 1. Definición central

**Composición ascendente en historias** = proceso por el cual unidades narrativas simples se combinan en unidades narrativas más complejas, preservando funciones locales y generando efectos globales.

Dicho de forma simple:

```text
microgestos → microescenas → escenas → secuencias → capítulos → arcos → trama → obra → universo
```

La clave no es solo que existan niveles, sino que cada nivel pueda funcionar como componente del nivel superior.

---

## 2. Principio funcional

Una unidad narrativa no se define únicamente por “qué aparece” en ella.

Se define por:

```text
qué función cumple dentro de una composición mayor.
```

Ejemplo:

```text
Una escena de un personaje corriendo no significa siempre lo mismo.
```

Puede ser:

1. **Huida:** corre para escapar.  
2. **Búsqueda:** corre para llegar a alguien.  
3. **Entrenamiento:** corre para mejorar.  
4. **Desesperación:** corre porque ya no tiene opciones.  
5. **Transición:** corre para mover la historia entre lugares.  
6. **Comedia:** corre de forma ridícula.  
7. **Heroísmo:** corre hacia el peligro.  
8. **Derrota:** corre aunque ya sabemos que no llegará a tiempo.  

La misma acción física puede cumplir funciones narrativas distintas.

---

## 3. Escalas narrativas

### Nivel 0 — Microgesto

Unidad mínima de expresión corporal o visual.

Ejemplos:

- apretar un puño,
- desviar la mirada,
- caer una lágrima,
- abrir una puerta,
- sonreír,
- temblar.

Función: concentrar una señal emocional, intencional o narrativa mínima.

---

### Nivel 1 — Microescena

Unidad breve con una intención narrativa simple.

Ejemplos:

- personaje empieza a correr,
- personaje escucha un ruido,
- personaje descubre una pista,
- personaje esconde un objeto.

Función: producir un movimiento narrativo elemental.

---

### Nivel 2 — Escena

Unidad narrativa completa con situación, tensión y cambio.

Ejemplos:

- discusión,
- persecución,
- revelación,
- combate,
- despedida,
- descubrimiento.

Función: transformar la situación de personajes, información o mundo.

---

### Nivel 3 — Secuencia

Conjunto de escenas orientadas a un mismo proceso narrativo.

Ejemplos:

- huida por la ciudad,
- entrenamiento del protagonista,
- investigación de un misterio,
- preparación para la batalla.

Función: desarrollar una fase reconocible de la historia.

---

### Nivel 4 — Capítulo

Unidad editorial o narrativa que agrupa secuencias.

Función: ofrecer una unidad de consumo, avance o cierre parcial.

---

### Nivel 5 — Arco

Conjunto de capítulos o secuencias que desarrollan un conflicto mayor.

Ejemplos:

- arco de traición,
- arco de entrenamiento,
- arco de caída,
- arco de redención,
- arco de guerra.

Función: transformar una condición importante de la historia.

---

### Nivel 6 — Trama

Organización global de conflictos, transformaciones y relaciones causales.

Ejemplos:

- ascenso del héroe,
- corrupción del poder,
- pérdida de inocencia,
- venganza,
- restauración del orden.

Función: dar dirección global a la obra.

---

### Nivel 7 — Obra completa

Sistema narrativo cerrado o relativamente cerrado.

Función: contener una experiencia narrativa completa.

---

### Nivel 8 — Universo narrativo

Conjunto de reglas, personajes, instituciones, lugares, conflictos y posibilidades que pueden sostener múltiples obras.

Función: permitir expansión, derivación y recomposición.

---

## 4. Analogía con programación

La composición ascendente en historias puede compararse con la composición en software:

```text
expresión → función → módulo → servicio → feature → aplicación → ecosistema
```

Equivalencia aproximada:

```text
microgesto      ≈ expresión
microescena     ≈ función
escena          ≈ módulo
secuencia       ≈ servicio
capítulo/arco   ≈ feature
obra            ≈ aplicación
universo        ≈ ecosistema
```

Esta analogía es útil porque muestra que una historia puede construirse como ensamblaje de unidades reutilizables.

---

## 5. Invariantes

La composición ascendente narrativa requiere:

1. **Unidades distinguibles.**  
   Debe poder identificarse dónde termina una unidad y comienza otra.

2. **Función local.**  
   Cada unidad debe hacer algo dentro del sistema narrativo.

3. **Composabilidad.**  
   Las unidades deben poder conectarse con otras.

4. **Escala.**  
   Debe haber niveles superiores que agrupen niveles inferiores.

5. **Transformación.**  
   La combinación debe producir un efecto mayor que la simple suma.

6. **Dependencia contextual.**  
   Una misma unidad puede cambiar de función según dónde se inserte.

---

## 6. Dominio de variación

La composición ascendente puede aplicarse a:

- manga,
- cómic,
- novela,
- cine,
- teatro,
- videojuegos,
- series,
- videos de YouTube,
- campañas narrativas,
- proyectos de contenido digital.

Puede variar el medio, pero se conserva la lógica:

```text
unidades simples → ensamblaje → estructura compleja.
```

---

## 7. Relación con estructuras cognitivas

Esta idea es importante porque permite pensar una estructura cognitiva compleja como ensamblaje de estructuras cognitivas simples.

Por ejemplo:

```text
idea → método → modelo → cApp → sistema → teoría
```

En narrativa:

```text
gesto → escena → secuencia → arco → obra
```

En ambos casos, la complejidad no aparece de golpe. Se construye por composición.

---

## 8. Fórmula de cierre

```text
Composición ascendente = unidades simples con función + reglas de ensamblaje + emergencia de estructuras mayores.
```

Aplicado a historias:

```text
Una historia compleja no es una masa continua.
Es una arquitectura de escenas, microescenas y funciones narrativas ensambladas por niveles.
```
