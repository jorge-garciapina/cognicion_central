# Historial de cNode

Versiones anteriores, revisiones, prompts y notas que permiten reconstruir la evolución del concepto cNode.

La versión activa se conserva en `01_nucleo_cognitivo/cnode`.

## Papel dentro del artefacto integral

- **Función:** preservar la secuencia de versiones, prompts y decisiones que formaron el concepto cNode.
- **Entradas:** borradores, revisiones, ideas ontológicas y contratos sustituidos.
- **Salidas:** genealogía de invariantes, cambios de interfaz y alternativas descartadas.
- **Consumidores:** mantenimiento de cNode, análisis de compatibilidad y reconstrucción conceptual.
- **Límite:** ninguna versión de esta carpeta debe ensamblarse como activa salvo una decisión explícita de recuperación.
