# Genealogía de la Biblioteca Escénica Composable

Antecedentes que permiten reconstruir el nacimiento y la separación del modelo de Biblioteca Escénica Composable.

`escenas_reutilizables.md` captura la intuición inicial, comentarios de desarrollo y comandos que posteriormente se materializaron como documentos autónomos sobre capas expresivas, composición ascendente, canales como infraestructura y biblioteca escénica.

Para trabajo operativo deben consultarse las fuentes vigentes en `03_aplicaciones/creacion_de_contenido/biblioteca_escenica_composable` y `03_aplicaciones/creacion_de_contenido/modelos_expresivos`. Este antecedente se usa para genealogía, no para sustituirlas.

## Papel dentro del artefacto integral

- **Función:** explicar el origen común de la biblioteca escénica, los modelos expresivos y varias decisiones de composición.
- **Entradas:** intuición inicial, comentarios y comandos de desarrollo.
- **Salidas:** procedencia de conceptos luego materializados como documentos activos separados.
- **Consumidores:** mantenimiento de la biblioteca, modelos expresivos y análisis de evolución.
- **Límite:** este antecedente no debe usarse como contrato operativo frente al modelo y protocolo vigentes.
