# Genealogía de transferencia estructural

Versiones sustituidas y antecedentes de los métodos para trasladar formas funcionales entre dominios.

## Contenido

- `meta-metafora-v1.txt`: explicación introductoria que convirtió la metáfora en un método con anclas, relaciones, reglas, pruebas y criterios. Fue sustituida operativamente por `02_metodos_y_herramientas/transferencia_estructural/meta-metafora-v2.txt`.

Este material se consulta para reconstruir la evolución conceptual; no compite con la versión activa.

## Papel dentro del artefacto integral

- **Función:** conservar las versiones que precedieron a los métodos activos de mapeo y traducción entre dominios.
- **Entradas:** explicaciones y protocolos sustituidos de transferencia estructural.
- **Salidas:** diferencias de versión, decisiones metodológicas y ejemplos históricos.
- **Consumidores:** mantenimiento de Meta-Metáfora, auditoría y enseñanza de la evolución del método.
- **Límite:** la versión histórica no debe ejecutar nuevas transferencias cuando existe una versión activa posterior.
