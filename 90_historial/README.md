# 90_historial

Versiones inmutables, sustituidas, discusiones y material necesario para reconstruir la evolución conceptual.

No es la fuente predeterminada para trabajo operativo. Los documentos se consultan para auditoría, comparación, recuperación o genealogía.

## Papel dentro del artefacto integral

- **Función:** preservar estados anteriores y procedencia para que la evolución del sistema sea reversible y explicable.
- **Entradas:** versiones sustituidas, borradores cerrados, discusiones y antecedentes desplazados por fuentes activas.
- **Salidas:** genealogía, comparación, auditoría, recuperación y evidencia de cómo cambiaron los conceptos.
- **Consumidores:** gobierno, investigación histórica, resolución de contradicciones y mantenimiento.
- **Límite:** historial no es la fuente operativa predeterminada y nunca compite silenciosamente con una versión activa.
