# Historial de arquitecturas cognitivas

Ediciones sustituidas de compendios arquitectónicos.

Se conservan para comparación. La edición operativa más reciente reside en `01_nucleo_cognitivo/arquitecturas`.

## Papel dentro del artefacto integral

- **Función:** conservar ediciones arquitectónicas sustituidas para reconstruir cambios de organización y alcance.
- **Entradas:** compendios reemplazados por una edición activa posterior.
- **Salidas:** diferencias versionadas, decisiones descartadas y base para auditoría arquitectónica.
- **Consumidores:** revisiones del núcleo, comparación de versiones y explicación de cambios.
- **Límite:** estas ediciones son inactivas; no deben citarse como estado vigente cuando existe una versión posterior en el núcleo.
