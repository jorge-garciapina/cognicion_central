# Modelo TMC del Anattalakkhaṇa Sutta

**Versión:** 1.0  
**Tipo de documento:** modelo conceptual reutilizable  
**Sutta modelado:** _Anattalakkhaṇa Sutta_ / _Anatta-lakkhaṇa Sutta_, SN 22.59  
**Marco de modelado:** Teoría de Máquinas Cognitivas, Creación de Realidad, Fábrica de Adaptaciones Contextuales, Correlación Intercapa, Campo Interpretativo, Teoría de Lazo  
**Propósito:** modelar lo que el sutta estudia: no solo la tesis doctrinal del no-yo, sino el campo experiencial donde surge la apropiación identitaria.

---

## 0. Nota de orientación

Este documento no busca “traducir” el sutta a otra teoría ni reemplazar su lógica interna por una teoría externa. El objetivo es **modelar el objeto que el sutta estudia** usando el marco que venimos construyendo.

La diferencia es importante:

- Una reformulación doctrinal diría: “el sutta enseña que no hay yo”.
- Este modelo pregunta: **¿qué región de la experiencia está examinando el sutta para que esa conclusión sea posible?**

La respuesta de este documento es:

> El _Anattalakkhaṇa Sutta_ estudia el campo de manifestación de la experiencia humana en cuanto campo de apropiación identitaria; examina cómo la atribución de “yo”, “mío” y “mi sí mismo” se deposita sobre forma, sensación, percepción, formaciones y conciencia, y muestra que esa apropiación fracasa en todas esas capas porque todas comparten inconstancia, exposición a aflicción y sujeción al cambio.

## 1. Identificación mínima del sutta

### 1.1. Nombre

- **Pali:** _Anattalakkhaṇa Sutta_.
- **Transliteración común:** _Anatta-lakkhana Sutta_.
- **Referencia canónica:** SN 22.59, _Saṁyutta Nikāya_, sección de los agregados.
- **Traducciones habituales:** “Discurso sobre la característica de no-yo”, “Discourse on the Not-self Characteristic”.

### 1.2. Contexto narrativo mínimo

El discurso se sitúa cerca de Vārāṇasī, en el Parque de los Ciervos de Isipatana, dirigido al grupo de los cinco monjes. Dhammatalks señala que este discurso también es conocido como el _Anatta-lakkhaṇa Sutta_ y que, según el _Mahāvagga_, fue el primer discurso durante el cual los oyentes del Buddha se convirtieron en arahants.

### 1.3. Fuente primaria usada como base

La base textual principal para este modelo es SN 22.59 en traducción inglesa de Thanissaro Bhikkhu, complementada por SN 22.47 para precisar el fenómeno de la asunción de self sobre los agregados.

Fuentes:

- SN 22.59 — _The Five (Brethren)_ / _Pañca Sutta_, también conocido como _Anatta-lakkhaṇa Sutta_: https://www.dhammatalks.org/suttas/SN/SN22_59.html
- SN 22.47 — _Assumptions_ / _Samanupassanā Sutta_: https://www.dhammatalks.org/suttas/SN/SN22_47.html

## 2. Qué estudia el sutta

### 2.1. No estudia primero una entidad metafísica llamada “yo”

El sutta no comienza definiendo un alma, una sustancia o una entidad metafísica para luego negarla. El procedimiento es más concreto: toma aquello que aparece en la experiencia y que puede ser tomado como soporte de identidad.

Ese campo está organizado en cinco agregados:

1. **rūpa** — forma / materialidad / cuerpo.
2. **vedanā** — sensación / feeling / tono hedónico.
3. **saññā** — percepción / reconocimiento / marcación.
4. **saṅkhārā** — formaciones / fabricaciones / configuraciones mentales.
5. **viññāṇa** — conciencia.

El sutta no estudia estos agregados solo como lista descriptiva. Los estudia como **lugares de apropiación identitaria**.

### 2.2. Objeto formal del sutta

El objeto formal puede expresarse así:

```text
Objeto estudiado =
campo experiencial manifestado
+
operación de apropiación identitaria
+
criterio de invalidación de esa apropiación
```

O en formulación más compacta:

```text
El sutta estudia el campo donde la experiencia es convertida en identidad.
```

### 2.3. La triple fórmula de apropiación

La fórmula que el sutta desactiva aparece como:

```text
Esto es mío.
Esto soy yo.
Esto es mi sí mismo.
```

En inglés, Thanissaro traduce:

```text
This is mine.
This is my self.
This is what I am.
```

Este triple gesto no es decorativo. Modela tres niveles de apropiación:

| Fórmula               | Tipo de apropiación         | Función                                              |
| --------------------- | --------------------------- | ---------------------------------------------------- |
| “Esto es mío”         | apropiación posesiva        | el agregado queda inscrito como propiedad del sujeto |
| “Esto soy yo”         | apropiación identificatoria | el agregado queda tomado como identidad              |
| “Esto es mi sí mismo” | apropiación ontológica      | el agregado queda elevado a fundamento del sujeto    |

El sutta estudia cómo estos tres gestos se intentan fijar sobre los cinco agregados.

## 3. Criterio de examen del sutta

El sutta aplica una prueba estructural a cada agregado.

### 3.1. Prueba de soberanía

La primera prueba puede formularse así:

```text
Si X fuera self,
entonces X no conduciría a aflicción
y sería gobernable soberanamente.
```

El texto aplica esta prueba a forma y conciencia explícitamente, y por repetición el mismo patrón se extiende a sensación, percepción y formaciones.

### 3.2. Prueba de inconstancia

La segunda prueba puede formularse así:

```text
X es inconstante.
Lo inconstante es stressful / insatisfactorio / expuesto a tensión.
Lo inconstante, stressful y sujeto a cambio no es apto para ser apropiado como self.
```

### 3.3. Prueba de universalización

El sutta no se limita al agregado presente y cercano. Extiende el examen a cualquier forma, sensación, percepción, formación o conciencia:

- pasada,
- futura,
- presente,
- interna,
- externa,
- burda,
- sutil,
- común,
- sublime,
- lejana,
- cercana.

Esto es crucial para el modelado. La prueba no opera sobre un ejemplo local, sino sobre el **campo completo de apropiabilidad**.

### 3.4. Resultado de la prueba

El resultado no es simplemente una conclusión teórica. Es una reorganización del modo de relación con la experiencia:

```text
visión correcta
→ desencanto
→ despasión
→ liberación
```

En términos del modelo:

```text
evaluación correcta de los agregados
→ interrupción de la apropiación identitaria
→ debilitamiento del apego
→ cambio de régimen operativo del sujeto
```

## 4. Modelo base del campo estudiado

### 4.1. Nombre del modelo

**Modelo de Apropiación Identitaria sobre Agregados Condicionados**

### 4.2. Definición central

El modelo describe cómo una configuración experiencial compuesta por cinco agregados puede ser tomada erróneamente como soporte de identidad, y cómo el análisis de su inconstancia, exposición a aflicción y falta de soberanía invalida esa apropiación.

### 4.3. Elementos mínimos

```yaml
  problema: atribución de self a agregados condicionados
  operador_critico: discernimiento de inconstancia, aflicción y no-soberanía

```

### 4.4. Fórmula mínima

```text
Agregado manifestado
+ apropiación identitaria
+ examen de soberanía/inconstancia
= invalidación del self atribuido
```

### 4.5. Fórmula extendida

```text

→ aparece como forma / sensación / percepción / formación / conciencia

→ se revela no apto como self
→ se desactiva la apropiación
→ se reorganiza la relación con la experiencia
```

## 5. Los cinco agregados como regiones de apropiación

### 5.1. rūpa — forma

#### Definición operativa

Forma es la región material/corporal de la experiencia. Incluye el cuerpo propio y la dimensión física que aparece como soporte visible y tangible.

#### Tipo de apropiación que permite

```text
“Yo soy este cuerpo.”
“Mi identidad está fijada por mi forma.”
“Lo que le ocurre al cuerpo me define en sentido último.”
```

#### Criterio de invalidación

El cuerpo envejece, enferma, cambia, duele y no obedece por completo a la voluntad. Por tanto, no cumple el criterio de soberanía ni de estabilidad.

#### Lectura TMC

rūpa es una región de manifestación donde la identidad puede intentar estabilizarse por soporte material. En términos de Creación de Realidad, es una capa de ejecución perceptiva particularmente densa: aparece como lo más evidente, lo más próximo, lo más “mío”.

#### Error de lectura

Confundir evidencia de proximidad con fundamento ontológico.

```text
proximidad corporal ≠ identidad última
```

---

### 5.2. vedanā — sensación / feeling

#### Definición operativa

Vedanā no debe traducirse simplemente como emoción compleja. Es más preciso entenderla como tono hedónico de la experiencia:

- agradable,
- desagradable,
- neutral.

#### Tipo de apropiación que permite

```text
“Yo soy lo que siento.”
“Lo agradable me confirma.”
“Lo doloroso me amenaza.”
“Mi identidad depende de sostener cierto tono de experiencia.”
```

#### Criterio de invalidación

La sensación cambia, aparece y desaparece. No puede sostenerse de manera soberana. No basta querer sentir placer para que el placer permanezca; no basta querer eliminar lo doloroso para que desaparezca.

#### Lectura TMC

vedanā funciona como **marcador de valencia** dentro del campo interpretativo de la experiencia. No crea todavía una teoría del mundo, pero asigna una dirección primaria:

```text
acercamiento / rechazo / indiferencia
```

#### Error de lectura

Confundir valencia momentánea con verdad identitaria.

```text
“esto se siente agradable” ≠ “esto soy yo”
```

---

### 5.3. saññā — percepción / reconocimiento

#### Definición operativa

Saññā nombra la función de reconocer, marcar, distinguir, clasificar. Permite que algo aparezca como “esto” y no como flujo indiferenciado.

#### Tipo de apropiación que permite

```text
“Yo soy quien ve correctamente.”
“Mi identidad está en mi modo de reconocer el mundo.”
“Soy mis categorías.”
```

#### Criterio de invalidación

La percepción se equivoca, cambia, depende del contexto, de memoria, de lenguaje, de atención y de condiciones. No es soberana ni inmutable.

#### Lectura TMC

saññā puede modelarse como capa de recorte y legibilidad dentro de la ejecución perceptiva. No es recepción pasiva, sino selección configurada por condiciones.

#### Error de lectura

Confundir clasificación operativa con fundamento del sujeto.

```text
“yo reconozco X así” ≠ “yo soy esa estructura de reconocimiento”
```

---

### 5.4. saṅkhārā — formaciones / fabricaciones

#### Definición operativa

Saṅkhārā es una de las zonas más difíciles de traducir. Aquí se modela como el conjunto de formaciones, fabricaciones, tendencias, disposiciones, intenciones, impulsos y configuraciones que organizan la respuesta mental.

#### Tipo de apropiación que permite

```text
“Yo soy mi voluntad.”
“Yo soy mis decisiones.”
“Yo soy mis tendencias.”
“Yo soy mi estructura mental activa.”
```

#### Criterio de invalidación

Las formaciones son condicionadas. Cambian por hábito, educación, miedo, deseo, memoria, contexto, entrenamiento, trauma, atención y repetición.

#### Lectura TMC

saṅkhārā es la capa más cercana a una **política interna de configuración**. No solo aparece algo; el sistema se predispone, se inclina, fabrica respuestas, organiza posibilidades.

#### Error de lectura

Confundir capacidad configuradora con sujeto soberano.

```text
“hay formación de respuesta” ≠ “hay un yo dueño absoluto de esa respuesta”
```

---

### 5.5. viññāṇa — conciencia

#### Definición operativa

Viññāṇa es conciencia, pero no debe convertirse apresuradamente en “alma” o “testigo absoluto”. En el sutta, también la conciencia es examinada como agregado.

#### Tipo de apropiación que permite

```text
“No soy el cuerpo, pero soy la conciencia.”
“No soy mis emociones, pero soy el testigo.”
“No soy mis pensamientos, pero soy el darse cuenta.”
```

#### Criterio de invalidación

La conciencia, como agregado, también es inconstante, sujeta a cambio y no gobernable soberanamente. Por tanto, tampoco puede ser apropiada como self.

#### Lectura TMC

viññāṇa es la capa más sutil de manifestación apropiable. El sutta la incluye para impedir que la identidad se refugie en la última capa disponible del campo experiencial.

#### Error de lectura

Confundir manifestación consciente con fundamento incondicionado.

```text
“hay conciencia de experiencia” ≠ “la conciencia agregada es self”
```

## 6. Modelo de apropiación identitaria

### 6.1. Proceso base

```text
1. Aparece un agregado.
2. El agregado recibe valencia, reconocimiento o continuidad.
3. El sistema lo toma como posesión, identidad o fundamento.
4. Surge apropiación identitaria.
5. El sutta aplica criterio de examen.
6. La apropiación queda invalidada.
```

### 6.2. Tres formas de apropiación

```yaml
apropiacion_identitaria:
  posesiva:
    formula: "esto es mío"
    operacion: inscripción del agregado como propiedad
  identificatoria:
    formula: "esto soy yo"
    operacion: inscripción del agregado como identidad
  ontologica:
    formula: "esto es mi self"
    operacion: inscripción del agregado como fundamento último
```

### 6.3. Cuatro formas de falla

```yaml
fallas_de_apropiacion:
  falta_de_soberania:
    descripcion: el agregado no obedece plenamente a la voluntad
  inconstancia:
    descripcion: el agregado aparece, cambia y desaparece
  afliccion:
    descripcion: el agregado se presta a dis-ease, tensión, sufrimiento o insatisfacción
  sujecion_al_cambio:
    descripcion: el agregado no conserva identidad estable absoluta
```

### 6.4. Resultado

```yaml
resultado_del_examen:
  juicio: no_apto_como_self
  formula: "esto no es mío; esto no soy yo; esto no es mi self"
  efecto: interrupcion_de_apropiacion
```

## 7. Lectura desde Creación de Realidad

### 7.1. Correspondencia general

En el subgrafo de Creación de Realidad, la realidad no se trata como dato bruto. Aparece mediante condiciones internas y externas, ejecución perceptiva, evaluación, política de actualización y cierre de circuito.

El sutta estudia una zona muy específica de ese proceso:

```text
la zona donde lo aparecido se convierte en identidad.
```

### 7.2. Componentes TMC aplicados

| Nodo TMC                  | Función en el modelo del sutta                                                   |
| ------------------------- | -------------------------------------------------------------------------------- |
| Ontología de Condiciones  | explica que los agregados aparecen bajo condiciones, no como entidades absolutas |
| Ejecución Perceptiva      | plano donde los agregados se manifiestan como experiencia efectiva               |
| Criterio de Evaluación    | prueba de inconstancia, aflicción, cambio y no-soberanía                         |
| Política de Actualización | paso desde “veo esto correctamente” hacia “dejo de apropiarlo”                   |
| Cierre de Circuito        | reorganización completa del modo de relacionarse con la experiencia              |

### 7.3. Relectura de SN 22.59 en esta clave

```text
Campo de experiencia aparece
→ el sujeto lo apropia como self
→ el criterio del sutta evalúa la validez de esa apropiación
→ la apropiación falla
→ la relación con la experiencia se actualiza
→ el circuito de apego pierde combustible
```

### 7.4. Diferencia entre cambio conceptual y actualización estructural

El sutta no busca solo que el oyente acepte una proposición. Busca que el oyente vea la experiencia de tal modo que el circuito de apropiación ya no pueda cerrarse como antes.

En términos TMC:

```text
no basta modificar una creencia;
debe cambiar la política de actualización del sistema experiencial.
```

## 8. Lectura desde Campo Interpretativo

### 8.1. Campo Interpretativo de la experiencia

El sutta presupone que la experiencia no solo ocurre; es interpretada. El sistema recibe manifestaciones y les asigna estatuto.

Por tanto, podemos modelar un campo interpretativo interno:

```yaml
campo_interpretativo_experiencial:
  entrada:
    - forma
    - sensación
    - percepción
    - formaciones
    - conciencia
  regimen_interno_previsto_por_ignorancia:
    - apropiacion_posesiva
    - apropiacion_identificatoria
    - apropiacion_ontologica
  salida_no_examinada:
    - esto_es_mio
    - esto_soy_yo
    - esto_es_mi_self
  salida_examinada:
    - esto_no_es_mio
    - esto_no_soy_yo
    - esto_no_es_mi_self
```

### 8.2. Cambio de régimen interpretativo

El sutta modifica el campo interpretativo. Antes, la experiencia se interpretaba bajo ignorancia y apropiación. Después del examen, se interpreta bajo discernimiento.

```text
régimen de ignorancia → régimen de discernimiento
```

### 8.3. Salida diferencial

La misma entrada puede producir dos salidas distintas según el régimen interpretativo.

| Entrada     | Régimen ignorante                | Régimen discernido                         |
| ----------- | -------------------------------- | ------------------------------------------ |
| forma       | “esto soy yo”                    | “esto no es mío, no soy yo, no es mi self” |
| sensación   | “esto me define”                 | “esto es condicionado”                     |
| percepción  | “mi modo de ver es mi identidad” | “este reconocimiento es inconstante”       |
| formaciones | “yo soy mi voluntad”             | “estas configuraciones son condicionadas”  |
| conciencia  | “soy la conciencia”              | “esta conciencia agregada no es self”      |

## 9. Lectura desde Fábrica de Adaptaciones Contextuales

### 9.1. Qué aporta FAC aquí

La Fábrica de Adaptaciones Contextuales no debe usarse para convertir el sutta en “contenido adaptable”. Aquí se usa para analizar el objeto estudiado por el sutta:

```text
un mismo núcleo de apropiación identitaria puede proyectarse en varias capas experienciales.
```

### 9.2. Núcleo preservable

El núcleo que se preserva en todos los casos es:

```text
un agregado condicionado es apropiado como self.
```

O de forma expandida:

```yaml
nucleo_preservable:
  fenomeno: apropiacion_identitaria
  formula_apropiativa:
    - esto_es_mio
    - esto_soy_yo
    - esto_es_mi_self
  condicion_de_error: tomar_lo_condicionado_como_fundamento_incondicionado
```

### 9.3. Contextos de proyección

El núcleo se proyecta en cinco contextos experienciales:

```yaml
contextos_de_proyeccion:
  - forma_corporal
  - sensación_hedonica
  - percepción_reconocimiento
  - formaciones_configuradoras
  - conciencia_agregada
```

### 9.4. Adaptación contextual del mismo error

| Contexto    | Forma del error                        |
| ----------- | -------------------------------------- |
| cuerpo      | “soy este cuerpo”                      |
| sensación   | “soy lo que siento”                    |
| percepción  | “soy mi modo de reconocer”             |
| formaciones | “soy mis configuraciones y decisiones” |
| conciencia  | “soy la conciencia”                    |

### 9.5. Diagnóstico FAC

El sutta muestra que el error identitario es **portátil**. Puede moverse de una capa a otra sin cambiar de núcleo.

Por eso, el modelo debe distinguir:

- el núcleo del error,
- las capas donde el error se proyecta,
- las variaciones locales del error,
- el criterio común de invalidación.

```text
mismo núcleo + distinta capa experiencial = variación contextual del mismo error identitario
```

## 10. Lectura desde Correlación Intercapa

### 10.1. Problema que resuelve

Si solo miramos horizontalmente, parecería que el sutta enumera cinco cosas distintas que “no son yo”. Pero el patrón es más profundo.

En todas las capas ocurre una covariación:

```text
forma falla como self
sensación falla como self
percepción falla como self
formaciones fallan como self
conciencia falla como self
```

La pregunta es:

```text
¿Por qué fallan todas?
```

### 10.2. Respuesta intercapa

No fallan por accidentes locales independientes. Fallan porque todas comparten una capa ontológica más profunda:

```text
condición de inconstancia + aflicción + cambio + falta de soberanía
```

### 10.3. Fórmula de correlación intercapa

```text
covariación visible:
  los cinco agregados fallan como self

insuficiencia explicativa local:
  no basta explicar cada fallo por separado

dependencia compartida:
  todos pertenecen al régimen de lo condicionado
```

### 10.4. Diagnóstico

El sutta no solo dice que cada agregado no es self. Muestra que la pretensión de self fracasa en todas las capas porque la estructura ontológica que las sostiene no permite soberanía, permanencia ni apropiación última.

### 10.5. Fórmula breve

```text
La repetición del fallo en cinco capas indica una dependencia común:
lo que aparece condicionado no puede funcionar como fundamento incondicionado.
```

## 11. Lectura desde Teoría de Lazo

### 11.1. Lazo ignorante

```text
aparición del agregado
→ valencia / reconocimiento / configuración
→ apropiación como mío/yo/self
→ apego
→ repetición del circuito
```

### 11.2. Lazo examinado

```text
aparición del agregado
→ evaluación por inconstancia / aflicción / cambio
→ no-apropiación
→ desencanto
→ despasión
→ liberación
```

### 11.3. Cambio de cierre

El sutta cambia el tipo de cierre del circuito.

Antes:

```text
experiencia → apropiación → apego → continuidad del sufrimiento
```

Después:

```text
experiencia → discernimiento → no-apropiación → liberación
```

### 11.4. Punto crítico

El sutta no elimina la aparición de agregados. Cambia el modo en que el sistema cierra sobre ellos.

```text
el agregado sigue apareciendo;
lo que se corta es el cierre apropiativo.
```

## 14. Discriminadores del modelo

Este modelo está bien aplicado si permite responder con precisión:

1. ¿Qué agregado está siendo examinado?
2. ¿Qué tipo de apropiación identitaria se intenta depositar sobre él?
3. ¿Qué criterio lo invalida como self?
4. ¿Qué capa TMC ayuda a explicar esa apropiación?
5. ¿La falla es local o intercapa?
6. ¿Qué cambia en el circuito de experiencia después del examen?

### 14.1. Prueba contra lectura doctrinal superficial

Si el análisis solo dice “el budismo enseña que no hay yo”, el modelo falla.

Debe mostrar:

```text
qué región de experiencia fue apropiada,
cómo fue apropiada,
por qué esa apropiación falla,
y qué reorganización produce la visión correcta.
```

### 14.2. Prueba contra psicologismo superficial

Si el análisis trata los agregados como simples “partes psicológicas”, el modelo falla.

Debe mostrar que los agregados son:

```text
regiones de manifestación apropiable
+
capas de posible cierre identitario
+
instancias de una condición compartida de inconstancia.
```

### 14.3. Prueba contra metafísica abstracta

Si el análisis discute el self como entidad abstracta sin pasar por los agregados, el modelo falla.

El sutta no empieza en una entidad metafísica. Empieza en el campo efectivo donde el self se asume.

## 15. Aplicación del modelo a otros casos

Este modelo puede utilizarse para estudiar cualquier caso donde una persona, sistema o cultura convierta una región de experiencia en identidad.

### 15.1. Ejemplos de uso

| Caso                       | Agregado dominante | Forma de apropiación                           |
| -------------------------- | ------------------ | ---------------------------------------------- |
| identidad corporal         | rūpa               | soy mi cuerpo / mi apariencia                  |
| hedonismo radical          | vedanā             | soy lo que siento / lo que disfruto            |
| identidad ideológica       | saññā              | soy mi modo de clasificar el mundo             |
| identidad voluntarista     | saṅkhārā           | soy mi voluntad / mis decisiones               |
| espiritualismo del testigo | viññāṇa            | soy la conciencia pura entendida como posesión |

### 15.2. Procedimiento de aplicación

```text
1. Identificar el agregado dominante.
2. Identificar la fórmula de apropiación.
3. Examinar soberanía, inconstancia, aflicción y cambio.
4. Determinar si la apropiación se sostiene.
5. Si no se sostiene, formular la salida de no-apropiación.
6. Reconstruir el cambio de lazo.
```

## 17. Fórmula final del modelo

```text
El Anattalakkhaṇa Sutta estudia la experiencia humana como campo de apropiación identitaria.

Los cinco agregados son regiones donde puede fijarse el gesto:
“esto es mío / esto soy yo / esto es mi self”.

El sutta aplica un criterio de examen:
lo que es inconstante, expuesto a aflicción, sujeto a cambio y no soberanamente gobernable
no puede funcionar como self.

La repetición de este fallo en las cinco capas muestra una correlación intercapa:
la razón del fallo no está solo en cada agregado aislado,
sino en su dependencia común respecto del régimen de lo condicionado.

La salida no es negar la experiencia,
sino cambiar el cierre del circuito:
de experiencia → apropiación → apego
a experiencia → discernimiento → no-apropiación → liberación.
```

## 18. Glosario mínimo

| Término                 | Uso en este modelo                                                              |
| ----------------------- | ------------------------------------------------------------------------------- |
| agregado                | región compuesta de experiencia apropiable                                      |
| apropiación identitaria | operación que toma un agregado como mío, yo o mi self                           |
| no-soberanía            | incapacidad de gobernar plenamente el agregado                                  |
| inconstancia            | condición de cambio, aparición y desaparición                                   |
| aflicción               | exposición a dis-ease, tensión o insatisfacción                                 |
| no-apropiación          | salida correcta del examen: no mío, no yo, no mi self                           |
| campo interpretativo    | estructura que recibe agregados y les asigna estatuto                           |
| correlación intercapa   | covariación visible entre capas explicada por condición común más profunda      |
| FAC                     | mecanismo para observar cómo el mismo núcleo se proyecta en contextos distintos |
| lazo                    | circuito de cierre entre experiencia, evaluación, apropiación y actualización   |

## 19. Cierre

Este modelo permite estudiar el _Anattalakkhaṇa Sutta_ sin reducirlo a una frase doctrinal. Su importancia no está solo en decir “los agregados no son self”, sino en mostrar **cómo la experiencia se vuelve candidata a identidad**, cómo esa candidatura fracasa y cómo ese fracaso reorganiza el circuito completo de relación con la experiencia.

Por eso, dentro del marco TMC, el sutta puede funcionar como un caso clásico de:

```text
diagnóstico de apropiación identitaria
+
invalidación intercapa
+
actualización del campo interpretativo
+
corte del lazo de apego
```
