## Ejemplo 2: aplicación del Paso 3 al modelo del estudiante respecto del aprendizaje del Tema A

### 2. Pregunta de trabajo

La pregunta en este paso es:

**¿qué elementos necesita el modelo para distinguir de manera estable distintas
configuraciones del estudiante respecto del aprendizaje del Tema A?**

No se pregunta todavía:

- cómo se enseñará;
- qué recurso se usará;
- qué adaptador operará después;
- ni qué materialización pedagógica se producirá.

### 3. Primera propuesta razonada de elementos relevantes

Bajo ese criterio, una primera lista razonable podría incluir:

- `familiaridad_con_el_tema`
- `tipo_de_dificultad_dominante`
- `modo_de_entrada_mas_efectivo`
- `grado_de_guia_requerida`
- `ritmo_de_progresion_compatible`
- `modo_de_verificacion_mas_fiable`
- `tolerancia_a_la_abstraccion`

### 4. Justificación de cada elemento propuesto

#### a) `familiaridad_con_el_tema`

Este elemento es relevante porque permite distinguir el grado y tipo de contacto
previo del estudiante con el Tema A.

No es lo mismo:

- no haber visto nunca el tema;
- haberlo oído solo superficialmente;
- o tener ya cierto manejo operativo.

Sin este elemento, el modelo perdería una diferencia básica de situación inicial.

#### b) `tipo_de_dificultad_dominante`

Este elemento es relevante porque no basta con saber que el estudiante “tiene
problemas”.

Hace falta distinguir de qué clase de problema se trata:

- conceptual;
- procedimental;
- expresivo;
- atencional;
- de transferencia;
- o mixto.

Sin este elemento, el modelo colapsaría dificultades distintas bajo una misma
etiqueta vaga.

#### c) `modo_de_entrada_mas_efectivo`

Este elemento es relevante porque permite distinguir cómo conviene abrir el
acceso inicial al Tema A para ese estudiante.

No es equivalente entrar por:

- definición;
- ejemplo resuelto;
- analogía;
- comparación;
- caso concreto;
- o esquema visual.

Este elemento describe una propiedad del caso, no una decisión todavía del
adaptador.

#### d) `grado_de_guia_requerida`

Este elemento es relevante porque distingue cuánto acompañamiento necesita el
estudiante para sostener el aprendizaje.

No es lo mismo:

- requerir guía alta;
- requerir guía media;
- o poder avanzar con guía baja.

Sin este elemento, el modelo no podría diferenciar casos que comparten una misma
dificultad pero difieren mucho en autonomía operativa.

#### e) `ritmo_de_progresion_compatible`

Este elemento es relevante porque describe la densidad de avance que el
estudiante puede sostener sin perder comprensión.

No es lo mismo:

- avanzar en micro-pasos;
- en pasos medios;
- o mediante saltos compactos.

Sin este elemento, el modelo perdería una diferencia importante en la dinámica
del aprendizaje.

#### f) `modo_de_verificacion_mas_fiable`

Este elemento es relevante porque no toda comprensión se verifica igual.

En algunos casos conviene verificar por:

- reexplicación;
- resolución guiada;
- resolución autónoma;
- comparación de casos;
- aplicación a nuevo caso;
- o síntesis.

Sin este elemento, el modelo no podría distinguir cómo se vuelve más legible la
comprensión real del estudiante.

#### g) `tolerancia_a_la_abstraccion`

Este elemento es relevante porque permite distinguir cuánto nivel de abstracción
puede sostener el estudiante antes de necesitar apoyo concreto.

No es equivalente:

- requerir anclaje constante en ejemplos;
- tolerar cierta abstracción intermedia;
- o poder sostener formulaciones abstractas durante más tiempo.

Sin este elemento, el modelo perdería una diferencia estructural importante en la
relación entre el estudiante y el contenido.

### 5. Qué elementos podrían parecer útiles pero no deberían entrar aquí

El Paso 3 también exige descartar candidatos.

Por ejemplo, podrían parecer útiles elementos como:

- `autor_del_diagnostico`
- `fecha_de_ultima_revision`
- `tipo_de_material_que_se_usara`
- `actividad_final_recomendada`

Pero esos elementos no pertenecen al mismo nivel:

- `autor_del_diagnostico`
- y `fecha_de_ultima_revision`

pertenecen a la documentación del proceso;

- `tipo_de_material_que_se_usara`
- y `actividad_final_recomendada`

pertenecen ya a la adaptación o a la materialización pedagógica.

Por eso, no deben entrar en este modelo base.

### 6. Qué inteligencia aporta la lista

La lista no es solo una acumulación de nombres.

En conjunto, los elementos cubren diferencias estructurales distintas:

- situación inicial frente al tema;
- clase de obstáculo dominante;
- forma de acceso más favorable;
- necesidad de acompañamiento;
- densidad de progresión compatible;
- modo de verificación;
- y relación con la abstracción.

Cada elemento entra porque captura una diferencia que no queda absorbida por los
demás.

### 7. Qué falta todavía después de esta propuesta

Aunque la lista está justificada, el modelo todavía no está completo.

Después de este paso todavía falta:

- describir semánticamente cada elemento con más precisión;
- fijar su función;
- distinguir su tipo de valor;
- fijar su espacio de valores posibles;
- declarar restricciones;
- y mostrar instancias válidas.

### 8. Fórmula condensada del ejemplo

En el caso del estudiante respecto del aprendizaje del Tema A, proponer elementos
relevantes significa seleccionar aquellos componentes sin los cuales el modelo
no podría distinguir configuraciones pedagógicamente significativas del caso, y
excluir tanto la metadocumentación como las decisiones que pertenecen ya a la
adaptación o a la materialización.
