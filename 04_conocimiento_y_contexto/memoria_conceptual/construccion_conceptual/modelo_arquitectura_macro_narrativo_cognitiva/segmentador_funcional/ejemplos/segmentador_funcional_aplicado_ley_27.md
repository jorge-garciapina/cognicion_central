## 1. Hipótesis general de arquitectura macro

La Ley N.º 27 desarrolla una arquitectura macro orientada a demostrar, operacionalizar y advertir sobre un principio de poder: la posibilidad de organizar la necesidad humana de creer alrededor de una figura, causa o sistema de convicciones.

El texto no avanza como una exposición neutral. Avanza como una **máquina de conversión del lector**: primero formula el principio, luego transforma ese principio en método, después lo prueba mediante observancias históricas, lo interpreta psicológicamente, lo condensa en metáfora, lo limita mediante invalidación y lo refuerza con textos marginales que actúan como ecos, parábolas y pruebas laterales.

La arquitectura macro detectada puede formularse así:

```txt
principio estratégico
  → manual procedimental
    → demostraciones históricas
      → interpretaciones psicológicas
        → metáfora integradora
          → advertencia de riesgo
            → refuerzos marginales/parabólicos
```

En términos narrativo-cognitivos:

```txt
el lector parte de una regla abstracta
  → aprende el mecanismo de fabricación de creencia
    → observa casos que confirman el mecanismo
      → recibe explicaciones interpretativas
        → integra la idea mediante una imagen
          → reconoce el peligro de la estrategia
            → consolida el patrón con textos complementarios
```

## 2. Criterio general de segmentación

La segmentación no se hizo por páginas ni por encabezados únicamente. Los encabezados visibles fueron usados como pistas, pero la unidad real de corte fue el cambio de responsabilidad funcional.

Los criterios usados fueron:

```txt
1. cambio de operación dominante;
2. cambio de escala;
3. cambio de régimen textual;
4. cambio de modo de prueba;
5. cambio de relación con el lector;
6. cambio de función dentro de la arquitectura macro;
7. aparición de texto marginal con función autónoma;
8. paso de regla a procedimiento, de procedimiento a caso, de caso a interpretación o de interpretación a advertencia.
```

## 10. Notas sobre zonas ambiguas

### Ambigüedad 1 — Observancias como casos o como manual encubierto

Las observancias pueden leerse como relatos históricos, pero también como manual indirecto. Cada caso muestra procedimientos prácticos que ya fueron anticipados por los cinco pasos. En la segmentación se decidió tratarlas como `observancia_historica`, con subfunción de demostración procedimental.

### Ambigüedad 2 — Textos marginales como anexos o como capa funcional

Los textos marginales no forman parte del cuerpo lineal principal, pero sí cumplen funciones claras dentro de la arquitectura cognitiva. Por eso se segmentaron como `orla_marginal_de_refuerzo`, no como material externo irrelevante.

### Ambigüedad 3 — Interpretaciones como comentario o como segundo nivel de ley

Las interpretaciones no son simples comentarios. Funcionan como traducción de caso a principio. Por eso se clasificaron como `interpretacion_explicativa` y no como glosa secundaria.

## 11. Conclusión del análisis

El capítulo funciona como una arquitectura altamente organizada. Su movimiento principal no es sólo “explicar una ley”, sino construir una experiencia de aprendizaje estratégico:

```txt
1. presenta una regla;
2. explica la vulnerabilidad humana que la hace posible;
3. ofrece un manual de explotación;
4. demuestra el método mediante casos;
5. interpreta los casos como principios psicológicos;
6. condensa todo en una metáfora;
7. advierte el riesgo;
8. refuerza el sistema con textos marginales.
```

El `segmentador_funcional` revela que el texto no debe dividirse solamente por encabezados. Los encabezados visibles coinciden en parte con la estructura funcional, pero dentro de ellos hay subsegmentos relevantes: cambios de escala, cambios de modo de prueba, cambios de fuente de autoridad, transiciones entre caso y principio, y textos marginales que funcionan como refuerzos autónomos.

La trayectoria detectada puede resumirse así:

```txt
necesidad de creer
  → fabricación de fe
    → organización de seguidores
      → explotación económica y simbólica
        → defensa grupal
          → prueba histórica
            → explicación psicológica
              → advertencia estratégica
```

Esta es la segmentación funcional del texto según el modelo especializado.
