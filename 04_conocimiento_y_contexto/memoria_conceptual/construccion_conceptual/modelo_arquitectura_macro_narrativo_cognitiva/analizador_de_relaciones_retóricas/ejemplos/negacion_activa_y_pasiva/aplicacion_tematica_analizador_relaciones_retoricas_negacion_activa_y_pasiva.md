# Aplicación temática del `analizador_de_relaciones_retóricas` — La negación activa y pasiva

**Texto fuente utilizado como corpus de apoyo:** `transcripcion_negacion_activa_y_pasiva.md`  
**Autor del texto fuente:** Jon Elster  
**Módulo aplicado:** `5. analizador_de_relaciones_retóricas`  
**Cambio de enfoque:** no se analiza la organización textual del capítulo; se analiza el **tema** que el capítulo desarrolla.  
**Objeto analizado:** la arquitectura retórica interna de la **negación activa y pasiva** como distinción lógico-cognitiva, psicológica, sociológica y política.

---

## 0. Cambio metodológico de enfoque

El análisis anterior trataba el capítulo como una secuencia textual. Identificaba secciones del ensayo, relaciones entre tramos y función de cada parte en la composición argumentativa de Elster.

El presente análisis cambia el foco. Aquí el capítulo completo se toma como **corpus de ejemplificación** de un fenómeno conceptual: la relación entre **negación activa** y **negación pasiva**.

Por tanto, la pregunta no es:

```txt
¿Cómo está organizado el texto de Elster?
```

sino:

```txt
¿Cómo está organizada retóricamente la propia distinción entre negación activa y negación pasiva?
¿Qué relaciones funcionales conectan sus componentes conceptuales?
Qué responsabilidades cumplen sus ejemplos, extensiones, paradojas y aplicaciones?
```

El capítulo se usa como una fuente que proporciona:

```txt
- formulaciones conceptuales;
- ejemplos lógicos;
- extensiones filosóficas;
- casos psicológicos;
- aplicaciones sociológicas;
- diagnósticos políticos;
- consecuencias históricas.
```

El resultado no es un mapa del texto, sino un mapa del **objeto conceptual**.

---

## 1. Definición del objeto temático

La **negación activa y pasiva** puede entenderse como una distinción entre dos modos de negar:

```txt
negación pasiva:
  ausencia, suspensión, falta de afirmación, no-presencia de un estado,
  no-creencia, no-deseo, no-obligación, no-acción.

negación activa:
  afirmación de lo contrario, oposición positiva, rechazo explícito,
  voluntad de destruir, prohibición, combate, contra-creencia.
```

En forma esquemática:

```txt
p:
  A cree p.

negación pasiva:
  No ocurre que A crea p.

negación activa:
  A cree no-p.
```

La distinción es sutil pero decisiva. La negación pasiva no equivale a la activa. No creer algo no es lo mismo que creer lo contrario. No desear algo no es lo mismo que desear que no ocurra. No obligar no es lo mismo que prohibir. No amar no es lo mismo que odiar. No tener fe no es lo mismo que combatir la fe.

La arquitectura retórica interna del concepto surge porque estas dos formas de negación se relacionan mediante contraste, confusión, desplazamiento, dependencia, paradoja e imposibilidad.

---

## 2. Tesis nuclear del análisis temático

La tesis del análisis es la siguiente:

```txt
La negación activa y la negación pasiva forman un sistema de relaciones
asimétricas: la activa intenta operar sobre objetos, creencias, deseos,
instituciones o estados que la pasiva simplemente deja ausentes; pero en muchos
casos la vía activa no produce pasividad, sino dependencia, reproducción,
contradicción o retorno de aquello que se intenta negar.
```

El capítulo muestra que la diferencia no es meramente lógica. Tiene consecuencias en muchos dominios:

```txt
lógica formal
lógica modal
creencia
conocimiento
obligación
intención
deseo
religión
psicología
psiquiatría
sociología institucional
oposición política
poder burocrático
proceso histórico
```

Por eso, la negación activa y pasiva no constituyen solamente una distinción conceptual. Constituyen una **arquitectura de relaciones**.

## 4. Inventario de unidades conceptuales del fenómeno

### UT_01 — Afirmación base

```yaml
unit_id: UT_01
nombre_conceptual: afirmación_base
formulación: A cree p / debe hacerse p / se desea x / existe un estado positivo.
responsabilidad: servir como punto de partida del sistema de negaciones.
dominio: lógico, modal, deóntico, epistémico, psicológico.
```

Toda distinción activa/pasiva necesita un estado base.

Ejemplos del capítulo:

```txt
A cree p.
Debe hacerse p.
A sabe p.
A desea hacer x.
Existe una sociedad o institución que funciona bajo cierto principio.
```

---

### UT_02 — Negación pasiva

```yaml
unit_id: UT_02
nombre_conceptual: negación_pasiva
definición_funcional: ausencia de afirmación positiva sin compromiso con lo contrario.
responsabilidad: introducir un espacio de no-posición, suspensión, indiferencia, posibilidad abierta o no-realización.
dominio: lógica formal, agnosticismo, no-obligación, no-deseo, olvido, indiferencia política.
```

La negación pasiva no destruye el objeto. Tampoco lo combate. Simplemente no lo afirma, no lo sostiene, no lo desea o no lo realiza.

Ejemplos:

```txt
No corresponde que A crea p.
No se sabe p.
No hay obligación de hacer p.
No se desea hacer x.
No hay fe.
No hay recuerdo.
```

---

### UT_03 — Negación activa

```yaml
unit_id: UT_03
nombre_conceptual: negación_activa
definición_funcional: afirmación positiva de lo contrario, rechazo, oposición o voluntad de supresión.
responsabilidad: introducir fuerza adversativa, oposición intencional o inversión del contenido base.
dominio: ateísmo militante, prohibición, anticomunismo, voluntad de olvidar, destrucción del objeto, crítica política.
```

La negación activa no es ausencia. Es posición contra.

Ejemplos:

```txt
A cree no-p.
Debe hacerse no-p.
Se prohíbe p.
Se desea destruir x.
Se lucha contra Dios.
Se lucha contra el comunismo.
Se intenta olvidar.
```

---

### UT_04 — Diferenciación activa/pasiva

```yaml
unit_id: UT_04
nombre_conceptual: diferenciación_activa_pasiva
responsabilidad: separar dos formas de negación que la mentalidad primitiva confunde.
función_retórica: contraste fundacional.
```

Esta unidad es el núcleo del modelo. Sin ella, todas las demás relaciones se colapsan.

La diferenciación permite ver que:

```txt
no creer ≠ creer lo contrario
no obligar ≠ prohibir
no desear ≠ desear lo contrario
no amar ≠ odiar
agnosticismo ≠ ateísmo militante
ausencia de oposición ≠ apoyo
ausencia de solución intencional ≠ imposibilidad de resultado
```

---

### UT_05 — Confusión activa/pasiva

```yaml
unit_id: UT_05
nombre_conceptual: confusión_activa_pasiva
responsabilidad: explicar el error cognitivo que produce maniqueísmo, estereotipo, contradicción institucional e irracionalidad política.
función_retórica: fuente de patologías conceptuales.
```

La confusión ocurre cuando se trata la negación pasiva como si fuera activa, o la activa como si fuera pasiva.

Ejemplos:

```txt
No estar a favor = estar en contra.
No creer = negar activamente.
No estar obligado = estar prohibido.
No apoyar al régimen = combatirlo.
No amar = odiar.
```

Esta confusión es una de las fuentes de la llamada “mentalidad primitiva” en el capítulo.

---

### UT_06 — Mentalidad binaria o primitiva

```yaml
unit_id: UT_06
nombre_conceptual: mentalidad_binaria_primitiva
responsabilidad: convertir la distinción fina en oposición total.
función_retórica: intensificación diagnóstica.
```

La mentalidad binaria no tolera zonas intermedias, suspensiones, abstenciones o diferencias entre ausencia y oposición. Su esquema es:

```txt
o se está a favor
o se está en contra
```

Este principio produce varios efectos:

```txt
- elimina la neutralidad;
- elimina la indiferencia;
- elimina la posibilidad de suspensión;
- convierte la falta de apoyo en hostilidad;
- convierte la no-aceptación parcial en rechazo total;
- convierte la crítica limitada en enemistad global.
```

---

### UT_07 — Extensión modal, deóntica y epistémica

```yaml
unit_id: UT_07
nombre_conceptual: extensión_modal_deontica_epistemica
responsabilidad: mostrar que la distinción activa/pasiva no se limita a creencias, sino que atraviesa necesidad, posibilidad, deber, permiso, saber y opinar.
función_retórica: generalización formal.
```

La distinción se extiende a operadores:

```txt
necesario / posible
obligatorio / permitido
saber / no saber
creer / no creer
querer / no querer
```

La consecuencia es que el fenómeno se vuelve estructural, no anecdótico.

---

### UT_08 — Negación de conjunción vs conjunción de negaciones

```yaml
unit_id: UT_08
nombre_conceptual: negación_de_conjunción_vs_conjunción_de_negaciones
responsabilidad: mostrar que no aceptar un conjunto no implica negar cada uno de sus elementos.
función_retórica: especificación lógica de la confusión.
```

Error típico:

```txt
No aceptar todo el sistema = rechazar todos sus componentes.
```

Distinción correcta:

```txt
No (p y q y r)
  no equivale necesariamente a:
no-p y no-q y no-r.
```

Aplicación:

```txt
Una plataforma política puede rechazarse como conjunto sin negar cada elemento.
Una persona puede fallar en un punto sin fracasar en todos.
Una institución puede tener aspectos criticables sin que todo sea inválido.
```

---

### UT_09 — Negación de descripciones definidas

```yaml
unit_id: UT_09
nombre_conceptual: negación_de_descripciones_definidas
responsabilidad: mostrar que negar un predicado no equivale siempre a negar la existencia del objeto descrito.
función_retórica: refinamiento lógico.
```

El capítulo menciona el problema de las descripciones definidas. La función de esta unidad es evitar que la negación se aplique sin distinguir entre:

```txt
negar que un objeto tenga una propiedad
negar que el objeto exista
negar que la descripción sea correcta
```

---

### UT_10 — Dependencia negativa

```yaml
unit_id: UT_10
nombre_conceptual: dependencia_negativa
responsabilidad: mostrar que una negación activa puede seguir dependiendo del objeto que combate.
función_retórica: paradoja central de la negación activa.
```

La negación activa necesita el objeto negado. Quien combate algo puede quedar estructuralmente atado a eso que combate.

Ejemplos:

```txt
El ateísmo militante depende de Dios como adversario.
El anticomunismo puede depender del comunismo como centro de identidad.
La voluntad de destruir puede conservar el objeto en forma de enemigo.
```

Esta es una relación muy importante: la negación activa no siempre libera del objeto; a veces lo conserva por inversión.

---

### UT_11 — Imposibilidad de producir negación pasiva mediante negación activa

```yaml
unit_id: UT_11
nombre_conceptual: imposibilidad_de_producir_pasividad_por_via_activa
responsabilidad: formular la paradoja pragmática central.
función_retórica: núcleo psicológico del modelo.
```

Hay estados que sólo existen si no se producen voluntariamente.

Ejemplos:

```txt
olvidar
ser espontáneo
ser inocente
creer sinceramente
tener fe
no pensar en algo
no desear algo
```

Intentar producirlos activamente puede impedirlos.

```txt
querer olvidar
  → mantiene activo el recuerdo.

querer ser espontáneo
  → destruye la espontaneidad.

querer no creer
  → mantiene la creencia como objeto de combate.
```

Esta relación es fundamental para comprender por qué muchas formas de negación activa fracasan.

---

### UT_12 — Mandato contradictorio

```yaml
unit_id: UT_12
nombre_conceptual: mandato_contradictorio
responsabilidad: mostrar la forma pragmática de la paradoja activa/pasiva.
función_retórica: ejemplificación psicológica.
```

Ejemplo:

```txt
Sé espontáneo.
Olvida esto.
No pienses en X.
Cree sinceramente.
No desees.
```

El mandato intenta producir activamente un estado que sólo puede existir pasivamente.

---

### UT_13 — Institución de la irracionalidad

```yaml
unit_id: UT_13
nombre_conceptual: institucionalización_de_la_confusión
responsabilidad: mostrar cómo una confusión lógica se convierte en principio sociológico.
función_retórica: transferencia de dominio lógico a dominio institucional.
```

En el caso de Ibansk, la confusión activa/pasiva no aparece solamente como error individual. Se vuelve forma de organización social.

Efectos:

```txt
- oposición tratada como enemistad;
- no cumplimiento tratado como sabotaje;
- permiso tratado como obligación;
- no obligación tratada como prohibición;
- solución tratada como problema;
- causalidad sustituida por culpa;
- poder orientado a bloquear en vez de producir.
```

---

### UT_14 — Poder negativo

```yaml
unit_id: UT_14
nombre_conceptual: poder_negativo
responsabilidad: describir un poder que puede impedir, destruir, bloquear y castigar, pero no crear positivamente.
función_retórica: aplicación política de la distinción.
```

El régimen de Ibansk aparece como capaz de:

```txt
bloquear
anular
prohibir
desviar
culpabilizar
destruir
paralizar
```

pero incapaz de:

```txt
crear intencionalmente
resolver efectivamente
producir excelencia
transformar deliberadamente
organizar causalmente el bien
```

Esto convierte la negación activa en principio institucional: la sociedad puede negar, pero no producir positivamente.

---

### UT_15 — Oposición atrapada en el régimen

```yaml
unit_id: UT_15
nombre_conceptual: oposición_atrapada
responsabilidad: mostrar que la negación activa del régimen puede reproducir la lógica del régimen.
función_retórica: paradoja política.
```

La oposición activa puede depender de aquello que combate. Puede organizarse en torno a la lógica del enemigo, aceptar sus términos o reproducir sus patrones.

Esto responde al patrón:

```txt
negar activamente X
  → quedar estructurado por X
```

La negación activa no garantiza exterioridad.

---

### UT_16 — Sustitución de causalidad por culpa

```yaml
unit_id: UT_16
nombre_conceptual: sustitución_de_causalidad_por_culpa
responsabilidad: mostrar cómo el régimen transforma problemas causales en problemas personales.
función_retórica: aplicación institucional y epistemológica.
```

La pregunta científica sería:

```txt
¿Cuál es la causa de este fenómeno?
```

La pregunta oficial se transforma en:

```txt
¿Quién tiene la culpa?
```

Esta sustitución es una forma de negación activa: no se comprende la causalidad; se busca un objeto personal sobre el cual descargar la negación.

---

### UT_17 — Negación de la negación: sentido lógico vs dialéctico

```yaml
unit_id: UT_17
nombre_conceptual: negación_de_la_negación
responsabilidad: llevar la distinción a escala histórica.
función_retórica: extensión máxima del modelo.
```

El capítulo distingue entre:

```txt
sentido lógico:
  negar la negación puede significar retorno al punto inicial.

sentido dialéctico:
  negar la negación puede producir una forma nueva, mediada por un proceso histórico.
```

Esta diferencia permite interpretar revolución, restauración y transformación histórica.

## 9. Diagnóstico retórico del fenómeno

La negación activa y pasiva forman un campo conceptual con varias tensiones internas.

### 9.1. Tensión 1 — Ausencia vs oposición

```txt
negación pasiva:
  no hay afirmación.

negación activa:
  hay afirmación contraria.
```

Responsabilidad retórica:

```txt
impedir que la ausencia sea leída como enemistad.
```

---

### 9.2. Tensión 2 — Neutralidad vs maniqueísmo

```txt
neutralidad:
  no se afirma p ni no-p.

maniqueísmo:
  todo no-apoyo se lee como oposición.
```

Responsabilidad retórica:

```txt
mostrar que la mentalidad binaria borra estados intermedios.
```

---

### 9.3. Tensión 3 — Acción voluntaria vs estado pasivo

```txt
acción voluntaria:
  intentar provocar un estado.

estado pasivo:
  sólo existe si no es producido directamente.
```

Responsabilidad retórica:

```txt
explicar paradojas como querer olvidar o querer creer sinceramente.
```

---

### 9.4. Tensión 4 — Poder para negar vs poder para crear

```txt
poder negativo:
  bloquear, prohibir, destruir, culpabilizar.

poder positivo:
  producir, transformar, crear, resolver.
```

Responsabilidad retórica:

```txt
mostrar que una institución puede ser poderosa como negación e impotente como creación.
```

---

### 9.5. Tensión 5 — Negación lógica vs negación dialéctica

```txt
negación lógica de la negación:
  retorno al punto inicial.

negación dialéctica de la negación:
  proceso mediado que produce otra configuración.
```

Responsabilidad retórica:

```txt
abrir la distinción al análisis histórico.
```

## 10. Patrones de relación dominantes

### 10.1. Contraste fundacional

```txt
negación pasiva ↔ negación activa
```

Todo el modelo depende de esta relación.

---

### 10.2. Confusión patológica

```txt
negación pasiva tratada como activa
negación activa tratada como pasiva
```

Es la fuente de maniqueísmo, estereotipo e irracionalidad institucional.

---

### 10.3. Transferencia de dominio

```txt
lógica
  → psicología
    → sociología
      → política
        → historia
```

El concepto se vuelve poderoso porque no se queda en el plano formal.

---

### 10.4. Paradoja pragmática

```txt
querer producir pasividad
  → mantiene activo el objeto
    → impide la pasividad buscada
```

Este patrón explica casos psicológicos, religiosos y políticos.

---

### 10.5. Asimetría institucional

```txt
capacidad de negar
  ≠ capacidad de crear
```

Este patrón explica el poder negativo.
