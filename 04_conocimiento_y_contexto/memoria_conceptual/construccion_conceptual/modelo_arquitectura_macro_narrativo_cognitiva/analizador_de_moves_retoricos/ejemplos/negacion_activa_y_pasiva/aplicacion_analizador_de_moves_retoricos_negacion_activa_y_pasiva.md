# Aplicación del `analizador_de_moves_retoricos` a **La negación activa y pasiva**

**Texto analizado:** `transcripcion_negacion_activa_y_pasiva.md`  
**Autor del texto:** Jon Elster  
**Módulo aplicado:** `10. analizador_de_moves_retoricos`  
**Tipo de análisis:** arquitectura de movimientos retóricos dentro de un ensayo teórico-crítico  
**Propósito del documento:** aplicar el modelo al texto sin mezclarlo con la descripción general del modelo.

---

## 1. Diagnóstico general

El texto de Elster no está organizado como una exposición lineal simple. Su arquitectura retórica combina varias operaciones:

```txt
presentación de un autor-objeto
  → aislamiento de una distinción lógica
    → formalización conceptual
      → genealogía filosófica
        → aplicación sociológica a Sinoviev/Ibansk
          → expansión política e institucional
            → reformulación histórico-dialéctica
              → cierre metodológico
```

El movimiento global no es únicamente “explicar la diferencia entre negación activa y pasiva”. Esa diferencia funciona como **instrumento de lectura** para reconstruir la racionalidad interna de una irracionalidad política. El texto empieza presentando a Sinoviev como alguien capaz de volver inteligible un universo irracional, y luego Elster demuestra que esa inteligibilidad puede explicarse mediante distinciones lógicas.

La tesis retórico-operativa del ensayo podría formularse así:

```txt
La distinción entre negación activa y negación pasiva permite comprender
fenómenos lógicos, psicológicos, institucionales e históricos que parecen
irracionales, especialmente en el universo soviético de Sinoviev.
```

La arquitectura de moves se organiza como un **ensayo de transferencia conceptual**: Elster toma una distinción lógica, la prueba en varios dominios, la estabiliza mediante genealogía filosófica, la aplica a Sinoviev y finalmente la eleva a una conclusión metodológica sobre la relación entre lógica formal, dialéctica e irracionalidad política.

## 3. Estado cognitivo inicial y final del lector

### Estado cognitivo inicial presupuesto

El texto presupone que el lector puede entender la irracionalidad soviética como caos, absurdo, arbitrariedad o patología histórica. También presupone que el lector puede conocer algunas oposiciones generales —racional/irracional, comunismo/capitalismo, lógica/dialéctica— pero no necesariamente dispone de una herramienta precisa para distinguir tipos de negación.

```yaml
estado_cognitivo_inicial:
  - el lector reconoce que Sinoviev analiza la sociedad soviética;
  - el lector puede asociar lo soviético con irracionalidad política;
  - el lector no posee todavía la distinción operativa entre negación activa y pasiva;
  - el lector puede confundir oposición, ausencia, indiferencia, prohibición y contradicción;
  - el lector aún no ve cómo una distinción lógica puede servir para ciencia política.
```

### Estado cognitivo final buscado

Al final, el lector debe comprender que la diferencia entre negar activamente y negar pasivamente no es un tecnicismo lógico, sino una herramienta para analizar paradojas del poder, la oposición, la intención, la historia y la irracionalidad política.

```yaml
estado_cognitivo_final:
  - el lector distingue ausencia, oposición, indiferencia, prohibición y contra-acción;
  - el lector comprende que muchas paradojas institucionales derivan de confundir esas formas;
  - el lector reconoce que Sinoviev construye un universo irracional pero inteligible;
  - el lector ve que lógica formal y análisis dialéctico no se excluyen;
  - el lector entiende que la irracionalidad política puede analizarse conceptualmente.
```

## 4. Inventario de moves retóricos

### M01. Territorialización comparativa de Sinoviev

```yaml
move_id: M01
nombre_funcional: territorializacion_comparativa_de_sinoviev
familia_de_move: territorializacion_autoral
escala: macro
rango_aproximado: inicio del ensayo
funcion_retorica: situar a Sinoviev dentro de una constelación literaria, lógica y sociológica
responsabilidad_narrativo_cognitiva: preparar al lector para ver a Sinoviev como objeto excepcional que requiere una lectura conceptual compleja
```

El texto empieza construyendo la autoridad y singularidad de Sinoviev. No lo introduce solamente como escritor, sino como una combinación difícil: lógico, novelista, sociólogo, satírico, heredero indirecto de tradiciones literarias y filosóficas. Este move cumple una función de **territorialización ampliada**: antes de explicar la negación activa y pasiva, Elster instala el tipo de objeto que exige esa herramienta.

El recurso principal es la comparación con varios nombres y estilos: Swift, Rabelais, Lewis Carroll, Solzhenitsyn, Simmel y Marx. La comparación con Marx es especialmente importante porque no opera como simple elogio; sitúa a Sinoviev como analista de un sistema social irracional que, sin embargo, tiene engranajes inteligibles.

```yaml
estado_cognitivo_de_entrada:
  lector_desconoce_o_no_ha_situado_a_sinoviev
operacion_sobre_el_receptor:
  construir_expectativa_de_lectura_compleja
estado_cognitivo_de_salida:
  lector_preparado_para_aceptar_que_sinoviev_requiere_un_marco_logico_sociologico
relacion_con_moves_posteriores:
  habilita_M02_al_presentar_la_necesidad_de_un_concepto_nuclear
centralidad: alta
```

Después de presentar a Sinoviev, Elster reduce el foco. El centro ya no será toda la obra, ni toda la sociedad soviética, sino una distinción lógica: negación activa y negación pasiva. Este move es decisivo porque convierte un universo alucinante en una estructura conceptual analizable.

El movimiento retórico es:


La función de este move es evitar que el ensayo se disperse. Declara que la distinción tiene doble uso: explicar la irracionalidad del régimen y servir como herramienta analítica para sus instituciones.


## 9. Diagnóstico de arquitectura retórica profunda

La arquitectura retórica profunda del ensayo puede formularse así:

```txt
Sinoviev revela una irracionalidad inteligible.
Para comprenderla, Elster aísla la distinción activa/pasiva.
Esa distinción se formaliza lógicamente.
Luego se amplía filosófica y psicológicamente.
Después se aplica a Ibansk como régimen social y político.
Finalmente se eleva a teoría del poder, la historia y el método.
```

El ensayo tiene, por tanto, una arquitectura de **instrumento conceptual en expansión**.

```yaml
tipo_de_arquitectura_macro_retórica:
```

No se trata de una arquitectura simple:

## 13. Conclusión aplicada

El texto de Elster tiene una arquitectura retórica especialmente compleja porque no se limita a explicar un concepto. Construye una herramienta, la legitima, la expande, la prueba y la convierte en método de lectura política.

La secuencia más profunda es:

```txt
Sinoviev hace inteligible lo irracional.
Elster muestra que esa inteligibilidad depende de una distinción lógica.
La distinción se vuelve herramienta sociológica.
La herramienta revela la estructura paradójica de Ibansk.
La estructura paradójica permite comprender poder, oposición e historia.
```

El `analizador_de_moves_retoricos` permite ver que cada tramo del ensayo cumple una responsabilidad funcional precisa. La arquitectura del texto no es acumulativa en sentido débil; es acumulativa en sentido metodológico: cada move amplía el alcance de la misma distinción hasta convertirla en principio de análisis político.

Por eso, la función global del ensayo puede formularse así:

```txt
convertir una distinción lógica entre negación activa y pasiva
 en una herramienta para comprender la irracionalidad política organizada.
```
