# Rhetorical Structure Theory

**Documento independiente.** Esta teoría se presenta sin mezclarla con otros modelos.

---

## Identificación general

**Nombre:** Rhetorical Structure Theory  
**Sigla:** RST  
**Campo principal:** lingüística, análisis del discurso, organización textual, procesamiento computacional del lenguaje.  
**Autores centrales:** William C. Mann y Sandra A. Thompson.  
**Obra principal:** Mann & Thompson (1988), _Rhetorical Structure Theory: Toward a functional theory of text organization_.

Rhetorical Structure Theory es una teoría descriptiva de la organización del texto. Su idea central es que un texto coherente no es una simple secuencia de oraciones, sino una estructura organizada mediante relaciones retóricas entre partes.

Estas relaciones explican cómo una unidad textual contribuye a otra.

Por ejemplo:

```txt
Una oración puede dar evidencia para otra.
Una sección puede elaborar una idea anterior.
Un ejemplo puede hacer más comprensible una afirmación.
Una objeción puede preparar una respuesta.
Una conclusión puede resumir una explicación previa.
```

## Pregunta principal de la teoría

La pregunta principal de RST es:

```txt
¿Cómo se organizan funcionalmente las partes de un texto para formar una unidad coherente?
```

También puede formularse así:

```txt
¿Qué relación retórica conecta una unidad textual con otra?
```

## Conceptos principales

### Unidad textual

Una unidad textual es un fragmento del texto que puede participar en una relación retórica. Puede ser una cláusula, oración, párrafo o sección, según el nivel de análisis.

### Relación retórica

Una relación retórica describe la función que una unidad cumple respecto de otra.

Ejemplos de relaciones:

```txt
elaboración
evidencia
justificación
contraste
condición
causa
resultado
preparación
motivación
resumen
reformulación
```

### Núcleo y satélite

En muchas relaciones RST se distingue entre núcleo y satélite.

El núcleo es la parte más central para los propósitos del texto. El satélite cumple una función de apoyo respecto del núcleo.

Ejemplo:

```txt
Núcleo:
  “El experimento mostró un cambio significativo.”

Satélite:
  “Los resultados fueron consistentes en tres grupos independientes.”
```

La segunda unidad puede funcionar como evidencia de la primera.

### Relaciones multinucleares

Algunas relaciones no tienen un solo núcleo y un satélite, sino varios núcleos de peso similar.

Ejemplo:

```txt
Punto 1
Punto 2
Punto 3
```

En una lista, los elementos pueden tener una relación multinuclear de enumeración o secuencia.

### Estructura jerárquica

RST propone que las relaciones pueden formar estructuras jerárquicas. Una relación puede unir unidades pequeñas; varias unidades unidas pueden formar una unidad mayor; esa unidad mayor puede relacionarse con otra parte del texto.

## Cómo funciona la teoría

Un análisis RST suele seguir estos pasos:

```txt
1. dividir el texto en unidades
2. identificar relaciones entre unidades
3. determinar núcleo y satélite cuando aplique
4. construir una estructura jerárquica
5. describir cómo cada parte contribuye a la coherencia del texto
```

Ejemplo simple:

```txt
[El producto falló en las pruebas iniciales.] [Por eso, el equipo rediseñó el sistema.]
```

Relación posible:

```yaml
relacion: resultado
unidad_1: causa o condición previa
unidad_2: resultado
```

Otro ejemplo:

```txt
[La propuesta parece costosa.] [Sin embargo, reduce riesgos a largo plazo.]
```

Relación posible:

```yaml
relacion: contraste
unidad_1: expectativa inicial
unidad_2: información que se opone o modifica la expectativa
```

## Aportes principales

RST aporta varias ideas importantes:

1. El texto tiene organización funcional.
2. Las partes se conectan mediante relaciones retóricas.
3. No todas las partes tienen el mismo peso; algunas son núcleos y otras satélites.
4. La coherencia puede describirse como una red jerárquica de relaciones.
5. La función de una unidad textual depende de su relación con otras unidades.
6. Una misma unidad superficial puede cumplir funciones distintas según el contexto.

## Usos posibles de la teoría

RST se ha usado en:

```txt
análisis del discurso
lingüística textual
generación automática de texto
resumen automático
análisis de coherencia
enseñanza de escritura
análisis argumentativo
procesamiento computacional del lenguaje
```

En análisis textual, sirve para explicar por qué un texto parece coherente o incoherente. En escritura, sirve para revisar si cada parte cumple una función clara. En procesamiento computacional, ha sido usada para tareas como análisis discursivo, generación y resumen.

## Ejemplo más desarrollado

Texto:

```txt
El sistema redujo el tiempo de respuesta en un 40%.
Esto es importante porque los usuarios abandonaban la plataforma cuando las cargas tardaban demasiado.
Sin embargo, la mejora aumentó el consumo de memoria.
Por esa razón, el equipo decidió optimizar el módulo de caché.
```

Un análisis RST podría identificar:

```yaml
unidad_1:
  texto: "El sistema redujo el tiempo de respuesta en un 40%."
  funcion: afirmación principal

unidad_2:
  texto: "Esto es importante porque..."
  relacion_con_unidad_1: justificación

unidad_3:
  texto: "Sin embargo, la mejora aumentó..."
  relacion_con_unidad_1: contraste o concesión

unidad_4:
  texto: "Por esa razón..."
  relacion_con_unidad_3: resultado
```

La estructura no es simplemente lineal. Cada unidad tiene una función respecto de otra.

## Límites de la teoría

RST es muy poderosa para describir relaciones funcionales entre partes de un texto, pero tiene algunos límites.

Primero, el análisis puede ser interpretativo. Diferentes analistas pueden proponer relaciones distintas para el mismo fragmento.

Segundo, RST describe relaciones retóricas, pero no siempre explica con detalle los procesos cognitivos internos del lector.

Tercero, RST puede volverse compleja en textos largos, porque el número de unidades y relaciones crece rápidamente.

Cuarto, la teoría describe organización textual, pero no es por sí sola una teoría completa de narración, memoria o comprensión.
