# Structure Building Framework

**Documento independiente.** Esta teoría se presenta sin mezclarla con otros modelos.

---

## Identificación general

**Nombre:** Structure Building Framework  
**Campo principal:** psicología cognitiva, comprensión del lenguaje, comprensión del discurso.  
**Autora central:** Morton Ann Gernsbacher.  
**Obras relevantes:** Gernsbacher (1991), Gernsbacher (1997), Gernsbacher (1990).

El Structure Building Framework es una teoría de la comprensión que propone que comprender consiste en construir estructuras mentales coherentes. Cuando una persona lee, escucha o interpreta información, no acumula datos de forma aislada. Construye una representación mental organizada.

La idea central es:

```txt
comprender = construir una estructura mental coherente
```

El marco propone que la comprensión implica tres procesos principales:

```txt
1. laying a foundation
2. mapping
3. shifting
```

En español, podríamos traducirlos como:

```txt
1. establecer una base
2. mapear o integrar información en la estructura activa
3. cambiar hacia una nueva estructura
```

## Pregunta principal de la teoría

La pregunta principal del Structure Building Framework es:

```txt
¿Cómo construyen las personas representaciones mentales coherentes durante la comprensión?
```

También puede formularse así:

```txt
¿Cuándo una persona integra información nueva en la estructura mental actual y cuándo necesita comenzar una nueva estructura?
```

## Conceptos principales

### Estructura mental

Una estructura mental es una representación organizada de la información comprendida. No es una lista de datos. Es una configuración coherente.

Ejemplo:

```txt
Si una persona lee una historia sobre una cena familiar,
construye una estructura mental con personajes, lugar, relaciones,
acciones, expectativas y posibles conflictos.
```

### Laying a foundation

Es el proceso inicial de construir una base para la comprensión. Cuando empieza una oración, un párrafo, una historia o una explicación, el lector establece una estructura inicial sobre la cual podrá integrar información posterior.

Ejemplo:

```txt
“En una ciudad pequeña, un médico descubrió un patrón extraño...”
```

Esta frase establece una base: lugar, protagonista, expectativa de descubrimiento y posible problema.

### Mapping

Mapping es el proceso mediante el cual la información nueva se integra en la estructura mental activa porque es coherente con ella.

Ejemplo:

```txt
“El patrón aparecía en pacientes que vivían cerca del río.”
```

Esta información se puede mapear sobre la estructura anterior: sigue el mismo marco del médico, el descubrimiento y el patrón.

### Shifting

Shifting ocurre cuando la información nueva ya no encaja bien con la estructura activa. Entonces el lector cambia hacia una nueva estructura.

Ejemplo:

```txt
“Pero el médico no estaba investigando una enfermedad, sino una estafa.”
```

Esta información puede obligar a reorganizar la representación. El lector cambia de una estructura médica a una estructura de engaño o investigación social.

### Supresión y mejora

El marco también se relaciona con procesos de supresión y mejora. La comprensión requiere activar información relevante y reducir la activación de información irrelevante. De otro modo, la representación mental se saturaría de asociaciones que no ayudan a comprender.

## Cómo funciona la teoría

El proceso general puede representarse así:

```txt
inicio de comprensión
  → establecimiento de base
    → información nueva coherente
      → mapping sobre estructura activa
        → información nueva poco coherente
          → shifting hacia nueva estructura
```

La comprensión avanza como una alternancia entre continuidad y cambio.

Mientras la información nueva encaja, se integra. Cuando deja de encajar, se inicia una nueva estructura.

## Ejemplo sencillo

Texto:

```txt
María entró al laboratorio con una libreta en la mano.
Había pasado meses estudiando los resultados.
De pronto, apagó las luces y comenzó la función.
El público aplaudió desde sus asientos.
```

Al principio, el lector establece una estructura de laboratorio científico. Las dos primeras oraciones se integran bien en esa estructura. Pero la tercera y cuarta oración fuerzan un cambio: quizá no era un laboratorio científico, sino un escenario, una demostración o una obra. El lector debe hacer shifting.

## Aportes principales

El Structure Building Framework aporta ideas importantes:

1. La comprensión es construcción activa.
2. La mente establece bases iniciales.
3. La información coherente se integra en estructuras activas.
4. La información incompatible provoca cambio de estructura.
5. Comprender implica activar información relevante y suprimir información irrelevante.
6. La continuidad y el cambio son procesos centrales de comprensión.

## Usos posibles de la teoría

El marco puede usarse para analizar:

```txt
comprensión lectora
comprensión oral
procesamiento narrativo
procesamiento de discurso
ambigüedad textual
cambio de tema
cambio de marco interpretativo
problemas de coherencia
```

También es útil para estudiar por qué ciertos textos son difíciles: pueden exigir demasiados cambios de estructura, establecer bases débiles o mezclar información incompatible sin señalización suficiente.

## Límites de la teoría

El Structure Building Framework es una teoría general de comprensión, no una teoría detallada de géneros textuales, argumentación o relaciones retóricas. Explica cómo se construyen representaciones mentales, pero no proporciona por sí sola una taxonomía completa de funciones discursivas.

Por ejemplo, puede explicar que un lector cambia de estructura, pero no siempre especifica si ese cambio corresponde a una objeción, un contraste, una evidencia o una analogía. Para eso se necesitan otros marcos más orientados a organización textual o retórica.
