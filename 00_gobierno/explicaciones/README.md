# Explicaciones de COGNICION_CENTRAL

Realizaciones pedagógicas y documentos autocontenidos que explican el sistema.

Son artefactos derivados: facilitan comprensión y transferencia, pero no sustituyen `00_gobierno/canon/COGNICION_CENTRAL_CANONICA.md`.

## Papel dentro del artefacto integral

- **Función:** traducir el sistema a representaciones pedagógicas, autocontenidas o analógicas.
- **Entradas:** canon, teoría, arquitecturas y decisiones ya documentadas.
- **Salidas:** explicaciones que reducen la dificultad de entrada y crean puentes hacia otros dominios.
- **Consumidores:** humanos, procesos de aprendizaje estructural y tareas de comunicación del sistema.
- **Límite:** una explicación simplifica o reexpresa; no crea por sí misma autoridad ni corrige las fuentes que explica.
