# 00_gobierno

Contiene los documentos con mayor autoridad operativa sobre COGNICION_CENTRAL.

## Contenido

- `canon`: estado vivo y vigente del sistema.
- `protocolos`: instrucciones para interpretar comandos y coordinar documentos.
- `registros`: política de organización, inventario y bitácora.
- `explicaciones`: realizaciones pedagógicas que explican el sistema sin reemplazar el canon.

## Regla de uso

Una explicación o protocolo puede orientar la operación, pero no modifica silenciosamente el canon. Toda contradicción debe exponerse al humano.

## Papel dentro del artefacto integral

- **Función:** actuar como plano de control de COGNICION_CENTRAL y decidir qué interpretación tiene precedencia.
- **Entradas:** comandos humanos, cambios de estado, archivos incorporados, resultados de revisión y conflictos documentales.
- **Salidas:** autoridad vigente, reglas de operación, inventarios, deudas y trazabilidad de cambios.
- **Consumidores:** todas las demás áreas; ninguna operación persistente queda fuera de este marco.
- **Límite:** gobierno coordina el artefacto, pero no sustituye la teoría del núcleo, los métodos ni el conocimiento de dominio.
