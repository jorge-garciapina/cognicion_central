# Registros de gobierno

Esta carpeta permite localizar, clasificar y auditar el conocimiento del proyecto.

- `POLITICA_DE_ORGANIZACION.md`: parámetros y árbol de decisión para ordenar archivos.
- `REGISTRO_DE_ARCHIVOS.md`: inventario trazable de los 54 archivos iniciales y de los ingresos posteriores.
- `BITACORA_DE_REORGANIZACION.md`: eventos de cambio estructural del repositorio.
- `DEUDAS_DE_ORGANIZACION.md`: referencias ausentes, ambigüedades y decisiones pendientes.

Todo ingreso, movimiento, cambio de estado o retiro debe reflejarse aquí.

## Papel dentro del artefacto integral

- **Función:** mantener la memoria administrativa y la observabilidad del repositorio como unidad.
- **Entradas:** eventos, hashes, rutas, clasificaciones, dependencias, decisiones, anomalías y deudas.
- **Salidas:** inventario físico, política organizativa, bitácora de cambios y lista explícita de pendientes.
- **Consumidores:** procesos de recuperación, ingreso, auditoría, serialización y mantenimiento futuro.
- **Límite:** registrar una afirmación, archivo o estructura no demuestra su validez conceptual ni le concede autoridad superior.
