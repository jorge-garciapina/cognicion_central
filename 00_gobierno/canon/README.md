# Canon vivo

Esta carpeta contiene exclusivamente la fuente canónica vigente de COGNICION_CENTRAL.

- El archivo sin sufijo de versión es el documento vivo.
- Las fotografías versionadas se conservan en `90_historial/canon`.
- Una actualización requiere autorización humana, trazabilidad, changelog y versionado.

## Papel dentro del artefacto integral

- **Función:** conservar la declaración de identidad y el estado de máxima precedencia del sistema.
- **Entradas:** únicamente decisiones humanas explícitas aprobadas mediante el procedimiento de cambio canónico.
- **Salidas:** invariantes, alcance y restricciones que gobiernan la interpretación de todo el repositorio.
- **Consumidores:** gobierno, núcleo, métodos, aplicaciones y cualquier serialización del artefacto integral.
- **Límite:** no recibe automáticamente inferencias, documentos frecuentes, explicaciones ni propuestas provisionales.
