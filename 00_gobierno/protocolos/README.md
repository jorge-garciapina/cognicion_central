# Protocolos

Instrucciones de interpretación y operación que conectan el canon con interfaces como el chat y con aplicaciones particulares.

Los protocolos no son memoria canónica por sí mismos. Si contienen una propuesta todavía no integrada, debe conservarse su estado provisional.

## Protocolos disponibles

- `cognicion_central.md`: antecedente provisional de integración entre el canon y una configuración de chat heredada.
- `PROMPT_CENTRAL_INSTALACION_COGNICION_CENTRAL_EN_CHATGPT_v0_1_0.txt`: protocolo activo para reconocer el artefacto central de un solo TXT, reconstruir su repositorio virtual e instalar capacidades mediante una superposición contextual dentro de proyectos de ChatGPT.

## Papel dentro del artefacto integral

- **Función:** convertir autoridad y comandos en reglas de interacción y coordinación ejecutables por humanos o IA.
- **Entradas:** canon, intención humana, artefacto central, contexto operativo y restricciones de aplicación.
- **Salidas:** instrucciones de interpretación, secuencias de actuación y criterios para resolver ambigüedades.
- **Consumidores:** interfaces conversacionales, aplicaciones y procesos que necesitan decidir cómo actuar.
- **Límite:** un protocolo provisional no modifica el canon ni puede extender sus permisos de manera implícita.
