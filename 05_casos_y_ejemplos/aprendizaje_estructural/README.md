# Casos de APRENDIZAJE_ESTRUCTURAL

Casos completos que ejecutan la secuencia ancla, mapeo, objetivo, límites, desanclaje, transferencia y operación.

La especificación de la aplicación reside en `03_aplicaciones/aprendizaje_estructural`.

## Papel dentro del artefacto integral

- **Función:** demostrar el ciclo completo de aprendizaje estructural en dominios concretos.
- **Entradas:** aplicación pedagógica, estructura ancla, objetivo, correspondencias, límites y tareas de transferencia.
- **Salidas:** recorridos observables de comprensión, desanclaje y operación independiente.
- **Consumidores:** docentes, aprendices, revisores de la aplicación y diseñadores de nuevos casos.
- **Límite:** el éxito explicativo de un caso no valida por sí solo toda la aplicación ni todas las analogías posibles.
