# Estudios y casos sistémicos

Estudios autocontenidos que reconstruyen un dominio como sistema y distinguen fuentes, modelo e hipótesis.

Se usan como evidencia, repertorio de puentes y prueba de métodos estructurales.

## Papel dentro del artefacto integral

- **Función:** reconstruir dominios complejos como sistemas autocontenidos y exponer relaciones entre fuente, modelo e hipótesis.
- **Entradas:** fuentes del dominio, método estructural, criterios de sistema y preguntas de investigación.
- **Salidas:** modelos sistémicos, analogías controladas, evidencia situada y límites de interpretación.
- **Consumidores:** aprendizaje estructural, explicaciones, transferencia y evaluación de arquitecturas.
- **Límite:** un estudio no convierte su dominio en modelo universal ni concede a una analogía autoridad sobre las fuentes.
