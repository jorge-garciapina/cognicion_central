# 05_casos_y_ejemplos

Instancias que hacen visible, enseñan o ponen a prueba una estructura.

Los casos pueden producir evidencia de funcionamiento, pero no sustituyen la definición del núcleo o método que ejemplifican.

## Papel dentro del artefacto integral

- **Función:** hacer observable una estructura mediante instancias que permitan comprenderla, compararla o ponerla a prueba.
- **Entradas:** definiciones activas, métodos, aplicaciones, dominio del caso y fuentes pertinentes.
- **Salidas:** demostraciones, pruebas de transferencia, evidencia situada, fallos y contraejemplos.
- **Consumidores:** aprendizaje, validación, explicaciones, diseño de nuevas aplicaciones y búsqueda cognitiva.
- **Límite:** un caso no sustituye la estructura que instancia ni permite generalizar fuera de sus condiciones sin justificación.
