# CASOS — COMMAND CENTER COGNICION_CENTRAL

Casos de prueba para verificar normalización, riesgo, autorización, planificación y persistencia.

## Papel dentro del artefacto integral

- **Función:** demostrar y poner a prueba la operación del Command Center con prompts concretos.
- **Entradas:** especificación de comandos, métodos y aplicación Command Center.
- **Salidas:** fixtures, resultados esperados y criterios de aceptación.
- **Consumidores:** validación manual, futuras pruebas automatizadas y desarrollo del runtime.
- **Límite:** los casos no son reglas canónicas; validan reglas definidas en capas superiores.
