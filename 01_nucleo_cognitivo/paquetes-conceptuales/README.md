# Paquetes conceptuales

## Qué es esta carpeta

Esta carpeta contiene los paquetes conceptuales del proyecto. Aquí se reúnen discusiones que han alcanzado un nivel suficiente de madurez, consistencia y estabilidad como para ser tratadas como base teórica del sistema.

Si otras zonas del proyecto conservan exploración, génesis o pensamiento en desarrollo, esta carpeta conserva formulaciones que pueden considerarse relativamente acabadas dentro del estado actual del trabajo.

En términos prácticos, esta carpeta constituye el núcleo teórico más estable del proyecto.

## Qué significa “paquete conceptual”

Un paquete conceptual no es simplemente un tema, una nota extensa o un documento aislado. Es una unidad teórica con suficiente coherencia interna como para:

- sostener una idea de forma relativamente estable;
- servir de referencia para desarrollos posteriores;
- aportar vocabulario fuerte;
- funcionar como base para crear otros temas;
- permitir expansión disciplinada;
- y ofrecer un punto de apoyo para modelado, proyección o implementación.

El término “paquete” es importante porque implica cierta modularidad. Cada paquete concentra una región del pensamiento con identidad propia, pero a la vez puede conectarse con otros paquetes y con el grafo general del proyecto.

## Función dentro del sistema

Esta carpeta cumple una función distinta y central dentro de la arquitectura general del proyecto.

Su función es:

- fijar teoría;
- preservar formulaciones consolidadas;
- ofrecer base semántica relativamente estable;
- servir como referencia canónica para futuras construcciones;
- y actuar como soporte para expandir la teoría sin perder coherencia.

En otras palabras: aquí se encuentra la capa del proyecto más cercana a lo que puede llamarse “la teoría” en sentido fuerte.

## Qué tipo de material contiene

En esta carpeta se espera encontrar:

- conceptos suficientemente estabilizados;
- estructuras teóricas con alto valor fundacional;
- paquetes que sirven como base de nuevos desarrollos;
- unidades conceptuales que pueden alimentar el grafo;
- material que ya no debe leerse solo como exploración, sino como formulación de referencia.

Esto no significa que un paquete conceptual sea intocable o absolutamente definitivo. Significa, más bien, que ha superado una etapa de exploración y puede ser usado como base confiable de trabajo.

## Cómo debe leerse esta carpeta

La lectura de esta carpeta debe ser distinta a la de incubación conceptual o transcripciones de apuntes.

Aquí conviene leer buscando:

- qué estructura teórica ya quedó fijada;
- qué conceptos funcionan como fundamento;
- qué definiciones o relaciones deben tratarse como referencia principal;
- qué parte del grafo puede apoyarse en este contenido;
- y qué desarrollos futuros deben construirse respetando esta base.

En esta carpeta la pregunta principal ya no es “¿qué está intentando emerger?”, sino “¿qué ya puede tomarse como punto de apoyo relativamente sólido?”.

## Por qué esta carpeta es importante

Esta carpeta es importante porque evita que el proyecto dependa únicamente de material disperso, intuiciones momentáneas o formulaciones todavía inestables.

Su existencia permite:

### 1. Tener una base de referencia

Cuando surgen nuevas preguntas, comparaciones o construcciones, esta carpeta ofrece el lugar desde donde comenzar con mayor estabilidad.

### 2. Evitar la improvisación permanente

Sin una capa teórica relativamente consolidada, todo desarrollo quedaría expuesto a reinvención constante. Los paquetes conceptuales reducen esa fragilidad.

### 3. Dar continuidad al crecimiento del proyecto

A medida que el proyecto se expande, esta carpeta permite que nuevas ideas no se agreguen de forma arbitraria, sino en continuidad con una base ya establecida.

### 4. Facilitar la proyección al grafo

Dado que el proyecto trabaja con un grafo de la Teoría de Máquinas Cognitivas y con una futura implementación en Cytoscape.js, esta carpeta es especialmente relevante como fuente de nodos, relaciones, criterios semánticos y estructuras suficientemente maduras para ser representadas con mayor formalidad.

### 5. Servir como base para aplicaciones cognitivas

Si el proyecto busca facilitar la creación de aplicaciones cognitivas, entonces necesita una capa conceptual firme desde la cual combinar elementos sin perder sentido. Esta carpeta cumple esa función.

### 6. Permitir expansión disciplinada

Un paquete conceptual bien formado no solo explica algo; también abre un campo de crecimiento coherente. Puede dar origen a otros paquetes, casos, derivaciones o implementaciones.

## Relación con las otras carpetas principales

Esta carpeta debe entenderse en relación con las demás capas del proyecto:

- frente a `incubacion-conceptual`, esta carpeta representa mayor estabilidad;
- frente a `transcripciones-de-apuntes`, esta carpeta representa mayor formalización y menor dependencia del contexto de origen;
- frente al grafo general, esta carpeta se acerca más a la función de fuente teórica consolidada.

Dicho de forma simple:

- las transcripciones conservan génesis;
- la incubación conserva exploración;
- los paquetes conceptuales conservan consolidación.

## Qué puede hacerse con el contenido de esta carpeta

El contenido de esta carpeta puede usarse para:

- desarrollar nuevos temas;
- fundamentar análisis posteriores;
- crear o corregir nodos y aristas del grafo;
- servir de base para documentación futura;
- construir criterios interpretativos más firmes;
- alimentar interfaces, visualizaciones o herramientas del proyecto;
- y orientar aplicaciones cognitivas con mayor precisión.

## Regla práctica de uso

Cuando una idea necesite una base teórica confiable, esta carpeta debe consultarse primero.

Si una pieza proveniente de incubación o de apuntes ha madurado suficientemente, puede considerarse candidata a ser reformulada e incorporada aquí.

## Resumen funcional

Esta carpeta debe entenderse como:

- base teórica del proyecto;
- capa canónica de mayor estabilidad relativa;
- fuente sólida para expansión conceptual;
- soporte principal para desarrollar nuevos paquetes, temas y estructuras del grafo.

No es solo archivo temático. Es arquitectura conceptual consolidada.
