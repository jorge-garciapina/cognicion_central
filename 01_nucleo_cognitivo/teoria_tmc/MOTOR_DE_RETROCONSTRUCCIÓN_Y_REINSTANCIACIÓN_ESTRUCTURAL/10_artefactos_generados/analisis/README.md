# Análisis

Guarda navegación, campos, cortes, segmentación, extracción y análisis intermedios. Un análisis parcial declara huecos y no se presenta como arquitectura cerrada. Usa manifestation, field/cut y subgraph schemas.

Estructura mínima: `RUN-ID/manifest.yaml`, `manifestation.*`, `field_and_cuts.yaml`, `segmentation.yaml`, `subgraphs.yaml`, `validation.yaml` y `trace.yaml`. Se produce con [MRRE-PROC-RETRO](../../03_protocolos_operacionales/02_retroconstruccion.md) y los schemas [MRRE-SCHEMAS](../../02_contratos_y_schemas/manifestation_input.schema.yaml).
