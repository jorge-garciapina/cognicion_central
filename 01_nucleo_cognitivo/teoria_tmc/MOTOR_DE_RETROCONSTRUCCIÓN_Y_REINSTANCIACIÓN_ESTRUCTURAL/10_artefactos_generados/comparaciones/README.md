# Comparaciones

Guarda nivel/contexto, firmas, matrices, grafos de correspondencia, invariantes compartidos, pérdidas, incompatibilidades y decisiones de equivalencia. “Se parece” no es resultado válido.

Usa una matriz por mapping y conserva `PASS/PARTIAL/FAIL`, ruptura y evidencia siguiendo [MRRE-PROC-COMPARE](../../03_protocolos_operacionales/05_comparacion_y_transferencia.md). Ejemplo: [CASE-MRRE-REUTERS](../../09_casos_y_ejemplos/reuters/DOSSIER_OPERATIVO.md).
