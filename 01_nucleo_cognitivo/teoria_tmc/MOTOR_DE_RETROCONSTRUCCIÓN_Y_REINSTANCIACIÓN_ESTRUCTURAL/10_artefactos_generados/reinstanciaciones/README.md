# Reinstanciaciones

Guarda skeleton/binding refs, instancia, `STRUCTURE_PRESERVATION_DIFF`, huecos, reingreso, tests y autoridad. Un producto sin proceso de preservación no es una reinstanciación MRRE válida.

Persiste juntos `skeleton.yaml`, `binding.yaml`, instancia, `diff.yaml`, artefactos de reingreso y validación. La plantilla es [MRRE-WORKBOOK-H](../../03_protocolos_operacionales/07_libro_de_trabajo_y_algoritmos.md#plantilla-h-binding_and_diff); el proceso, [MRRE-PROC-REINSTATE](../../03_protocolos_operacionales/04_reinstanciacion.md).
