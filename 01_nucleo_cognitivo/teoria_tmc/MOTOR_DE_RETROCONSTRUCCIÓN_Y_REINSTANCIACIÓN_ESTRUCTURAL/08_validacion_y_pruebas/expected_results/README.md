# Expected results de prueba

Cada expected result selecciona propiedades, no una respuesta textual única. Debe declarar obligatorios, prohibidos, alternativas, certeza máxima, traces, fallos tolerables, métricas y thresholds.

Se construye desde `CASE_SPEC` conforme a [MRRE-COMP-CUT](../../04_runtime/componentes/02_cut_engine.md) y se valida con [MRRE-VAL-PLAN](../01_plan_de_verificacion_y_validacion.md). Los ejemplos están enlazados en [MRRE-CASE-INDEX](../../09_casos_y_ejemplos/README.md).
