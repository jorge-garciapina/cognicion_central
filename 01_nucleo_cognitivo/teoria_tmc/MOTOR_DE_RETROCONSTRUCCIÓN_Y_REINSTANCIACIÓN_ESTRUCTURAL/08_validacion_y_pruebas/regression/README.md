# Regression MRRE

Toda modificación de schema, invariante, patrón, adapter o componente compara baseline, dependientes, métricas, estados epistemológicos y promotion decision. Una diferencia aceptable debe estar autorizada y explicada.

El baseline está en [MRRE-REGRESSION-BASELINE](baseline_v0_1_0.yaml). Toda revisión usa [MRRE-VERSIONING](../../00_gobierno/03_estado_versionado_y_decisiones.md) y vuelve a ejecutar [MRRE-VAL-DOC](../04_validacion_de_referencias_y_operabilidad.md).
