# Integración con TMC y COGNICIÓN_CENTRAL

> **Proyecto:** COGNICIÓN_CENTRAL  
> **Entidad:** `MÁQUINA_DE_TRANSDUCCIÓN_COGNITIVA` (`MTC`)  
> **Versión de formalización:** `0.1.0`  
> **Fecha:** `2026-08-10`  
> **Estado:** `FORMALIZACIÓN PROPUESTA / NO CANÓNICA`  
> **Autoridad:** la incorporación al canon requiere decisión humana explícita.

## 1. Relación con Teoría de Máquinas Cognitivas

La TMC del proyecto concibe la máquina cognitiva como sistema de componentes integrables capaz de seleccionar modos de manifestación, producir estructuras internas, proyectarlas y componerlas. La plataforma cognitiva aloja procesos que convierten información en acción, decisión, representación, explicación, plan, diseño o inferencia.

La MTC propuesta NO reemplaza esa teoría. Introduce una **arquitectura aplicada de conversión entre dominios**:

```text
TMC
marco general de máquinas cognitivas
        ↓
MTC
patrón especializado en:
información → cognición → acción → manifestación
```

## 2. Posible clasificación cognitiva

La MTC completa tiene una naturaleza compuesta:

```text
FAM-Diseño:
  define componentes, interfaces e invariantes

FAM-Plan:
  ordena trayectoria I→EC→A→V→K→M

FAM-Método:
  posee procedimiento de instanciación y validación

FAM-Patrón-de-razonamiento:
  permite reconstruir manifestación→capacidad→acción→cognición→intervención
```

La familia dominante provisional es `Diseño`, con componentes Plan/Método.

## 3. Soberanía humana

La MTC puede describir mecanismos de influencia o diseño, pero sus objetivos y autorizaciones no se autodefinen.

```text
HUMANO
→ fija propósito y límites

MTC
→ modela/ejecuta sólo dentro de autorización
```

## 4. Feedback y corrección acumulativa

El bucle:

```text
intervención → mundo → evidencia → revisión
```

es compatible con la corrección acumulativa de COGNICIÓN_CENTRAL, siempre que feedback no sea confundido con verdad y la persistencia sea gobernada.
