# Relación con COGNICIÓN_CENTRAL

## 1. Rol del paquete

PIEA se propone como paquete conceptual reusable para identificar, describir y comparar dinámicas de integración acumulativa entre dominios.

## 2. Espacios lógicos

Según `[CC-BOOT]`:

```txt
CC://
  fuentes vigentes recuperadas del artefacto central

PROJECT://
  conversación, fuentes y decisiones del proyecto receptor

OVERLAY://
  bindings y configuraciones locales

OUTPUT://
  este paquete generado para revisión
```

La existencia del ZIP en `OUTPUT://` no lo promueve automáticamente a `CC://`.

## 3. Gobierno humano

El humano conserva autoridad para:

- aprobar el identificador PIEA;
- modificar el núcleo;
- aceptar o rechazar ejemplos;
- promover una versión al repositorio vivo;
- ordenar una nueva fotografía del artefacto central.

## 4. Portador y estructura

```txt
ZIP
  portador físico del paquete

archivos Markdown
  unidades direccionables

PIEA
  estructura cognitiva distribuida entre esas unidades
```

No debe confundirse el archivo comprimido con la estructura ni con una instalación activa.

## 5. Integración futura

La futura cognición local de PIEA deberá añadir mapa, política de navegación, operadores y validadores sin duplicar el contenido fuente. Esa tarea no forma parte de la versión `0.2.0`.
