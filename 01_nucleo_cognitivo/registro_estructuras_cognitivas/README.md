# REGISTRO DE ESTRUCTURAS COGNITIVAS

Subárea activa del núcleo de COGNICION_CENTRAL dedicada a inventariar estructuras cognitivas por identidad y operación, independientemente de los archivos que las portan.

El registro físico de archivos responde **dónde está un documento**. Este registro responde **qué estructura existe, cómo funciona, dónde se manifiesta y con qué nivel de confianza puede reutilizarse**.

## Documento rector

- `REGISTRO_DE_ESTRUCTURAS_COGNITIVAS_v0_1_0.md`: contrato inicial, método de frecuencia y catálogo de las primeras diez estructuras registradas.

## Entradas

- `estructuras_frecuentes/`: un documento por estructura seleccionada mediante BÚSQUEDA_COGNITIVA sobre el corpus completo.

## Estado

`A3 / LIVE` para el registro y `A3 / PROVISIONAL` para sus primeras entradas. La incorporación al núcleo está autorizada por el humano; la promoción de una entrada al canon requiere un comando canónico explícito y evaluación separada.

## Regla de actualización

Una entrada nueva debe declarar identidad, rol operativo, firma, invariantes, dominio de variación, funcionamiento, ejemplos trazables, relaciones, frecuencia o criterio de admisión, estado, versión y límites. Las copias exactas de un mismo contenido no cuentan como evidencias independientes.

## Papel dentro del artefacto integral

- **Función:** proporcionar el espacio de direcciones semántico de las estructuras cognitivas conocidas por el repositorio.
- **Entradas:** resultados de BÚSQUEDA_COGNITIVA, fuentes trazables, validación manual y criterios CS1-CS4.
- **Salidas:** identidades estructurales reutilizables, relaciones, firmas de búsqueda y estados de confianza.
- **Consumidores:** búsqueda, Ingeniería de Estructuras Cognitivas, cNodes, aplicaciones y procesos de recuperación.
- **Límite:** no reemplaza el registro físico de archivos ni convierte frecuencia, presencia o síntesis provisional en canon.
