# Diseño atencional

Principios y procedimientos transversales para diseñar piezas que funcionen bajo condiciones variables de atención.

`progressive_attention_enhancement.md` propone preservar un núcleo en baja atención, hacer legible la estructura en atención media y recompensar la observación profunda con capas adicionales coherentes.

Se ubica como método porque puede aplicarse a videos, documentos, diagramas, presentaciones, interfaces y otros formatos sin depender de una sola aplicación.

## Papel dentro del artefacto integral

- **Función:** adaptar la presentación de una estructura a distintos niveles de atención sin perder su núcleo.
- **Entradas:** contenido esencial, jerarquía informativa, medio, duración y condiciones de observación.
- **Salidas:** capas de lectura, señales de progresión y criterios de coherencia entre atención baja, media y profunda.
- **Consumidores:** creación de contenido, campos atencionales, diseño de interfaces y explicaciones.
- **Límite:** los principios no sustituyen pruebas con usuarios ni especificaciones actuales de una plataforma concreta.
