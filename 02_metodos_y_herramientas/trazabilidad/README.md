# Trazabilidad conceptual

Método para registrar origen, función, peso, transformación y estado de formalización de las ideas que componen una unidad.

Debe consultarse cuando una propuesta aspire a modificar un módulo o el canon.

## Papel dentro del artefacto integral

- **Función:** mantener enlazados origen, transformación, función local, peso y estado de cada idea utilizada.
- **Entradas:** claims, fragmentos, fuentes, decisiones, versiones y unidades de destino.
- **Salidas:** genealogías conceptuales, matrices de procedencia y rutas auditables desde fuente hasta resultado.
- **Consumidores:** gobierno, registro de estructuras, aplicaciones, análisis y cualquier propuesta de promoción.
- **Límite:** la trazabilidad demuestra procedencia y transformación; no prueba por sí sola verdad, calidad ni aprobación.
