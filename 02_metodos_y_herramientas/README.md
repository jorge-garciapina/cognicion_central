# 02_metodos_y_herramientas

Procedimientos y utilidades reutilizables por múltiples núcleos y aplicaciones.

- `definicion_conceptual`: construcción rigurosa de definiciones.
- `diseno_atencional`: principios transversales para piezas que operan bajo atención variable.
- `trazabilidad`: genealogía, composición y estado de las ideas.
- `artefactos`: definición, generación y refinamiento de fotografías cognitivas.
- `ingenieria_de_estructuras_cognitivas`: método en desarrollo para compilar intenciones, ensamblar unidades y validar grafos transferibles.
- `transferencia_estructural`: elevación de nivel, mapeo entre dominios y modelado fractal verificable.

Un método responde cómo producir o validar un resultado. Una aplicación responde para qué dominio u objetivo se utiliza.

## Papel dentro del artefacto integral

- **Función:** actuar como capa de transformación reusable entre las estructuras del núcleo y los objetivos de las aplicaciones.
- **Entradas:** intenciones, estructuras, fuentes, proyectos, corpus y restricciones de gobierno.
- **Salidas:** procedimientos, contratos, prompts operativos, análisis, validaciones y herramientas ejecutables.
- **Consumidores:** todas las aplicaciones y procesos de mantenimiento o serialización del repositorio.
- **Límite:** un método especifica cómo operar; no decide por sí solo el objetivo, la autoridad o la identidad total del sistema.
