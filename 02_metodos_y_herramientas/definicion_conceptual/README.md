# Definición conceptual

Métodos y plantillas para producir definiciones autónomas, operativas y con ambigüedad controlada.

Admite estructuras de definición general. Las definiciones de entidades particulares permanecen junto a su módulo.

## Papel dentro del artefacto integral

- **Función:** normalizar conceptos para que puedan compararse, reutilizarse y operar con ambigüedad controlada.
- **Entradas:** términos, fuentes, usos, relaciones, condiciones y problemas de interpretación.
- **Salidas:** definiciones autónomas, componentes semánticos y plantillas de verificación conceptual.
- **Consumidores:** núcleo, registros semánticos, métodos, aplicaciones y documentación de interfaces.
- **Límite:** definir con rigor no convierte una entidad particular en capacidad transversal ni resuelve evidencia empírica faltante.
